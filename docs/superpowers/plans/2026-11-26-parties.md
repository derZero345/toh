# Parties Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The GM puts characters into named parties; a player's HUD also shows characters that share a party with one of the player's own characters.

**Architecture:** A party is a name on a character (`Entity.party`, "" = none). It is stored in the save file (format v7) and sent in spawns and the full table (protocol 7). A new GM-only op `OP_SET_PARTY` changes it. A small module `src/party.c` answers "does this player share a party with this character?" and lists parties. `hud_can_see()` uses it, and the console gets `:c party` and `:party`.

**Tech Stack:** C11, SDL3, the existing test programs (`tests/save_test.c`, `tests/netmsg_test.c`, `tests/core_test.c` with `tests/core_stubs.c`) and the e2e scripts (`tests/e2e_net.sh`).

**Spec:** `docs/superpowers/specs/2026-11-26-parties-design.md`.

**Conventions:**
- **Commits:** end every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Build and test:** `make` (no warnings allowed), `make test` (every program prints `N checks, 0 failed`), `make e2e` (prints `OK` lines; opens windows).
- **Work happens on branch `parties`.**

**One deviation from the spec's test list:** `src/console.c` is not linked into any unit test, so `:c party` parsing is checked end to end (Task 6) instead of with a unit test. `:party`'s output comes from `party_log()` in `src/party.c`, which is unit-tested.

```c
 * one of their own (hud_can_see); :party lists the parties. Only the GM changes them (OP_SET_PARTY).
 * Design: docs/superpowers/specs/2026-11-26-parties-design.md */
#ifndef TOH_PARTY_H
#define TOH_PARTY_H

#include "app.h"

/* Are a and b characters in the same party (names compared ignoring ASCII case)? False without a party. */
bool party_shared(const Entity *a, const Entity *b);
/* Does the player own a character in e's party? */
bool party_visible(const Entity *e, const char *player);
/* Logs one line per party, in creation order: "Heroes: Mao (anna), Character #7 (NPC)". The party's name is
 * spelled as on its oldest member. viewer NULL: every party (the GM); else only the parties one of the viewer's
 * characters is in. With nothing to list: "No parties" / "None of your characters is in a party". */
void party_log(const char *viewer);

#endif
```

`src/party.c`:

```c
#include "party.h"

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <strings.h>

static bool is_character(const Entity *e) { return e && e->type == ENTITY_CHARACTER; }

static bool owned_by(const Entity *e, const char *player) {
    return e->owner[0] && strcasecmp(e->owner, player) == 0;
}

bool party_shared(const Entity *a, const Entity *b) {
    return is_character(a) && is_character(b) && a->party[0] && strcasecmp(a->party, b->party) == 0;
}

bool party_visible(const Entity *e, const char *player) {
    if (!is_character(e) || !e->party[0]) return false;
    for (int i = 0; i < gh->entities.count; i++) {
        const Entity *c = gh->entities.items[i];
        if (is_character(c) && owned_by(c, player) && party_shared(c, e)) return true;
    }
    return false;
}

static int by_id(const void *a, const void *b) {
    uint32_t x = (*(Entity *const *)a)->id, y = (*(Entity *const *)b)->id;
    return (x > y) - (x < y);
}

void party_log(const char *viewer) {
    int n = gh->entities.count, lines = 0;
    Entity **es = malloc(sizeof(Entity *) * (size_t)(n ? n : 1));
    if (!es) abort();
    if (n) memcpy(es, gh->entities.items, sizeof(Entity *) * (size_t)n);
    qsort(es, (size_t)n, sizeof(Entity *), by_id);
    for (int i = 0; i < n; i++) {
        Entity *first = es[i];
        if (!is_character(first) || !first->party[0]) continue;
        bool listed = false; /* an older member came first */
        for (int j = 0; j < i && !listed; j++) listed = party_shared(es[j], first);
        if (listed || (viewer && !party_visible(first, viewer))) continue;
        char line[1024];
        int len = snprintf(line, sizeof(line), "%s:", first->party);
        for (int j = i; j < n && len < (int)sizeof(line); j++) {
            if (!party_shared(es[j], first)) continue;
            char name[CHAR_NAME_MAX + 16];
            entity_display_name(es[j], name, sizeof(name));
            len += snprintf(line + len, sizeof(line) - (size_t)len, "%s %s (%s)", j == i ? "" : ",", name,
                            es[j]->owner[0] ? es[j]->owner : "NPC");
        }
        console_log("%s", line);
        lines++;
    }
    if (!lines) console_log("%s", viewer ? "None of your characters is in a party" : "No parties");
    free(es);
}
```
