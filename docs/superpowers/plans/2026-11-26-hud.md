# Bottom HUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A modular HUD at the bottom centre replaces the top-right HP panel: a dark panel with rows from a config
table (resources, stamina, a slider, a hotbar) and a floating tab for the character shown. Only HP, stamina and the
name are real; everything else is a placeholder.

**Architecture:**
- `src/hud.c` is the core. It stores values that the game publishes by key, computes and caches the layout from
  `HUD_ROWS` (`src/hud_config.c`), hit-tests, turns input into `HudEvent`s and draws by calling one
  `HudComponent` per element type (`src/hud_widgets.c`).
- Tokens live in `src/hud_theme.c` and icons in `src/hud_icons.c`.
- `src/hud_game.c` is the only HUD file that reads game state. It chooses the character, publishes values every
  drawn frame and handles events.
- `graphics.c`, `input.c`, `console.c` and `main.c` only call `hud_game_*` / `hud_*` entry points.

**Tech Stack:** C11, SDL3, the Vulkan 2D API in `src/draw.h`, ImageMagick for e2e checks.

Spec: `docs/superpowers/specs/2026-11-26-hud-design.md`.

**Conventions:**
- `make test` runs five test programs, each printing `N checks, 0 failed`. The HUD tests live in
  `tests/core_test.c` (no window; drawing and textures are stubbed in `tests/core_stubs.c`).
- `make 2>&1 | grep -i warn` prints nothing.
- e2e (`make e2e`) needs a display, ImageMagick and `make build/toh-relay`. The tiling window manager may resize
  windows; rerun once on a strange failure.
- Work on a branch `hud` (`git checkout -b hud`). Commit messages are plain sentences ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Guides describe only what is in the game (CLAUDE.md); they are updated in Task 9, before the branch is merged.
- Run all commands from the repository root.

/* HUD look: every size, colour and font size the HUD components use. Sizes are logical pixels at scale 1; the
 * HUD multiplies them by its scale (console font size / 16, shrunk in narrow windows). */
#ifndef TOH_HUD_THEME_H
#define TOH_HUD_THEME_H

#include "util.h"

typedef enum {
    HUD_ACCENT_RED, HUD_ACCENT_GREEN, HUD_ACCENT_BLUE, HUD_ACCENT_GOLD, HUD_ACCENT_VIOLET, HUD_ACCENT_GREY,
    HUD_ACCENT_COUNT
} HudAccent;

typedef struct {
    /* layout */
    float margin;   /* to the window edge, the open console and the toolbox */
    float padding;  /* inside the panel */
    float rowGap, elemGap;
    float radius;   /* panel and tab corners */
    float minScale; /* narrow windows: the HUD shrinks down to this fraction of its scale */
    /* text */
    float font, smallFont;
    /* bars */
    float barH, thinBarH, barMinW, barFrameLine, markerLine, tickOverhang;
    /* stat pills */
    float pillW, pillH, pillEdge, pillPad;
    /* slider */
    float sliderTrack, sliderKnob, sliderLabelW, sliderMinW;
    /* hotbar */
    float slot, slotGap, slotRadius, slotIconPad, slotTextPad;
    /* target tab */
    float tabH, tabGap, tabPad, tabIcon, closeSize;
    /* shadow: layers spreading by shadowStep each */
    float shadowStep;
    int shadowLayers;
    /* colours */
    Color panel, border, shadow, text, textDim;
    Color barBg, barFrame, dyingBg, marker, emptyLine;
    Color slotBg, veil, hover, pressed;
    Color accent[HUD_ACCENT_COUNT], accentLight[HUD_ACCENT_COUNT];
} HudTheme;

extern const HudTheme HUD_THEME;

#endif

- [ ] **Step 3: Write `src/hud.h`** (the whole interface; later tasks implement it).

```c
/*
 * Bottom HUD: a panel at the bottom centre with rows of elements, and a tab above it for the character shown.
 *
 * The HUD knows nothing about the game. Each drawn frame the game side (hud_game.c) publishes values under keys;
 * the config (hud_config.c) lists rows of elements, each showing the value with its key; components
 * (hud_widgets.c) draw one element type each; tokens (hud_theme.c) hold every size and colour; icons are looked up
 * by key (hud_icons.c). What the user does comes back as HudEvents to the handler hud_game.c registers.
 *
 * How to ...
 *   Add a stat:            publish it in hud_game.c's publish_placeholders (later: real data), e.g.
 *                          hud_set_pill("pill.left", "STR", "3"), and make sure a row in hud_config.c has an
 *                          element with that key.
 *   Add / move / remove a row element or a row:
 *                          edit HUD_ROWS in hud_config.c; nothing else changes. hud_config_check (run by make test)
 *                          catches unknown types, repeated keys and too many rows, elements or slots.
 *   Add a hotbar slot:     raise .slots of the hotbar element (at most 10: the number keys) and publish the slot
 *                          with hud_set_slot("hotbar", index, &slot). Unpublished slots are empty.
 *   Add an element type:   add it to HudElementType (before HUD_ELEMENT_COUNT), write its HudComponent in
 *                          hud_widgets.c and put it into HUD_COMPONENTS. If it shows a new kind of value, add the
 *                          struct to HudValue and a hud_set_* function in hud.c.
 *   Swap icons:            change the table in hud_icons.c; everything else refers to icons by key.
 *   Real content:          the placeholders (stat pills, the "Value" slider, the slot states) are published in
 *                          hud_game.c's publish_placeholders(); replace them with game data there, and react to slot
 *                          and slider events in hud_game.c's on_event().
 */
#ifndef TOH_HUD_H
#define TOH_HUD_H

#include <stdbool.h>
#include <stddef.h>

#include "hud_theme.h"
#include "vk_renderer.h"

#define HUD_MAX_ROWS 8
#define HUD_MAX_ROW_ELEMENTS 8
#define HUD_MAX_SLOTS 10 /* one per number key */
#define HUD_MAX_VALUES 32
#define HUD_MAX_MARKERS 4
#define HUD_TEXT_MAX 48
#define HUD_KEY_MAX 24

typedef struct { float x, y, w, h; } HudRect;

static inline bool hud_rect_contains(HudRect r, float x, float y) {
    return x >= r.x && x < r.x + r.w && y >= r.y && y < r.y + r.h;
}

/* ---- config (hud_config.c) ---- */

typedef enum { HUD_BAR, HUD_PILL, HUD_SLIDER, HUD_HOTBAR, HUD_ELEMENT_COUNT } HudElementType;

typedef struct {
    HudElementType type;
    const char *key;   /* which published value it shows; unique */
    HudAccent accent;
    const char *label; /* placeholder text where the element has one (pill, slider); may be NULL */
    int slots;         /* hotbar: 1..HUD_MAX_SLOTS */
    bool two_sided;    /* bar: -max..max; the left half is the zone below 0 */
    bool thin;         /* bar: the thin variant */
} HudElement;

typedef struct {
    const HudElement *elements;
    int count;
} HudRow;

extern const HudRow HUD_ROWS[];
extern const int HUD_NROWS;

/* 0 if rows[0..n) is a valid config, else -1 with the reason in err. */
int hud_config_check(const HudRow *rows, int n, char *err, size_t cap);
/* Uses another config (tests); NULL = HUD_ROWS. */
void hud_use_config(const HudRow *rows, int n);

/* ---- values ---- */

typedef enum { HUD_MARK_LINE, HUD_MARK_TICK } HudMarkerStyle;
typedef struct {
    float at; /* fraction of the frame, like the spans */
    HudMarkerStyle style;
} HudMarker;

/* Spans are fractions of the frame: 0..1 is the frame; a two-sided bar also draws -1..0 left of it. */
typedef struct {
    float solidLo, solidHi; /* the solid fill */
    float lightLo, lightHi; /* the lighter "just lost" part; nothing when lo >= hi */
    HudMarker markers[HUD_MAX_MARKERS];
    int nmarkers;
    char text[HUD_TEXT_MAX];
} HudBar;

typedef struct { char label[HUD_TEXT_MAX], value[HUD_TEXT_MAX]; } HudPill;
typedef struct { char label[HUD_TEXT_MAX]; int value, min, max; } HudSlider;

typedef enum { HUD_SLOT_EMPTY, HUD_SLOT_UNAVAILABLE, HUD_SLOT_AVAILABLE } HudSlotState;
typedef struct {
    HudSlotState state;
    char icon[HUD_KEY_MAX]; /* icon key; "" = none */
    int count;              /* shown when > 0 */
    int cooldown;           /* > 0: shown over the icon, and the slot can't be used */
} HudSlot;

typedef struct {
    char key[HUD_KEY_MAX];
    HudElementType type;
    union {
        HudBar bar;
        HudPill pill;
        HudSlider slider;
        HudSlot slots[HUD_MAX_SLOTS]; /* HUD_HOTBAR */
    };
} HudValue;

void hud_begin_frame(void); /* forgets the previous frame's values and target */
void hud_set_target(const char *name, const char *extra, bool can_close);
void hud_set_bar(const char *key, const HudBar *bar);
void hud_set_pill(const char *key, const char *label, const char *value);
void hud_set_slider(const char *key, const char *label, int value, int min, int max);
void hud_set_slot(const char *key, int index, const HudSlot *slot); /* other slots of that key stay */
const HudValue *hud_value(const char *key); /* published this frame under key, or NULL */

typedef struct {
    bool shown;
    char name[HUD_TEXT_MAX], extra[HUD_TEXT_MAX]; /* extra: e.g. "+2 (exhausted)" */
    bool canClose;
} HudTarget;
const HudTarget *hud_target(void);

/* ---- screen and layout ---- */

typedef struct {
    float winW, winH;
    float bottom; /* the HUD stays above this y: the window height, or the top of the open console */
    float left;   /* and right of this x: the toolbox */
    float scale;  /* 1 = the token sizes */
} HudScreen;

void hud_set_screen(const HudScreen *s);
bool hud_visible(void);
void hud_set_visible(bool on);
/* A part of the current layout: an element key, "<hotbar key>.<1..slots>", "panel", "tab" or "tab.close".
 * False if the HUD is hidden, there is no such part, or the tab (or its close button) is not shown. */
bool hud_part_rect(const char *part, HudRect *out);
bool hud_contains(float x, float y); /* over the panel or the tab; false while hidden */
float hud_layout_scale(void);        /* the scale the current layout uses */
int hud_layout_count(void);          /* how often the layout was computed (tests) */
void hud_draw(void);

/* ---- input and events ---- */

typedef enum { HUD_EV_TARGET_CLOSED, HUD_EV_SLOT_USED, HUD_EV_SLIDER_CHANGED } HudEventType;
typedef struct {
    HudEventType type;
    const char *key; /* the element's key; NULL for HUD_EV_TARGET_CLOSED */
    int slot;        /* HUD_EV_SLOT_USED: 0..9 */
    int value;       /* HUD_EV_SLIDER_CHANGED */
} HudEvent;

void hud_set_event_handler(void (*fn)(const HudEvent *ev));
/* Left button. True when the HUD used the press: the map must ignore it. */
bool hud_mouse_down(float x, float y);
/* Updates hover; true only while a press that started on the HUD is held (the map must ignore the motion). */
bool hud_mouse_move(float x, float y);
/* Left button. True if the press had started on the HUD. */
bool hud_mouse_up(float x, float y);
/* Number key for slot 0..9 (keys 1..9, 0). True if the slot was used. */
bool hud_key(int slot);

/* ---- components (hud_widgets.c) ---- */

typedef struct {
    int hover, press;            /* flat element index row * HUD_MAX_ROW_ELEMENTS + element, -1 = none */
    int hoverSub, pressSub;      /* inside it, e.g. the hotbar slot; -1 = none */
    bool hoverClose, pressClose; /* the tab's close button */
} HudUiState;

typedef enum { HUD_MOUSE_DOWN, HUD_MOUSE_MOVE, HUD_MOUSE_UP } HudMouseKind;
typedef struct {
    HudMouseKind kind;
    float x, y;
} HudMouse;

typedef struct {
    bool flex; /* shares the row's free width */
    float (*min_width)(const HudElement *e, float scale);
    float (*height)(const HudElement *e, float scale);
    /* v is NULL when nothing (or a value of another type) is published under the key: draw the empty state.
     * self is the element's flat index, to compare with ui->hover / ui->press. */
    void (*draw)(const HudElement *e, HudRect r, const HudValue *v, const HudUiState *ui, int self, float scale);
    /* Optional (NULL = no mouse handling). DOWN and UP come to the element the press started on; MOVE comes to it
     * while the press is held, otherwise to the element under the pointer. Returns true after filling *ev (type,
     * slot, value; hud.c adds the key) to send an event. v may be NULL. */
    bool (*mouse)(const HudElement *e, HudRect r, HudValue *v, HudMouse m, HudUiState *ui, int self, float scale,
                  HudEvent *ev);
} HudComponent;

extern const HudComponent *const HUD_COMPONENTS[HUD_ELEMENT_COUNT];

/* fixed parts */
void hud_draw_panel(HudRect r, float scale);
float hud_tab_width(const HudTarget *t, float scale);
void hud_draw_tab(HudRect r, HudRect close, const HudTarget *t, const HudUiState *ui, float scale);
/* hotbar geometry, shared by drawing, input and hud_part_rect */
HudRect hud_slot_rect(HudRect hotbar, int i, float scale);
int hud_slot_at(const HudElement *e, HudRect hotbar, float x, float y, float scale); /* -1 = none */
bool hud_slot_usable(const HudSlot *s);

/* ---- icons (hud_icons.c) ---- */

void hud_icons_init(const char *resource_dir);
void hud_icons_free(void);
Texture *hud_icon(const char *key); /* NULL if the key is unknown or the icon isn't loaded */

#endif
```

```c
/* HUD icon registry: icons are referred to by key everywhere else, so swapping the set means changing this table.
 * Files live in resources/images/hud/. */
#include "hud.h"
#include "image.h"

#include <stdio.h>
#include <string.h>

static const struct { const char *key, *file; } ICONS[] = {
    { "placeholder", "placeholder.png" },
};
#define NICONS ((int)(sizeof(ICONS) / sizeof(ICONS[0])))

static Texture *textures[NICONS];

void hud_icons_init(const char *resource_dir) {
    for (int i = 0; i < NICONS; i++) {
        char path[1024];
        snprintf(path, sizeof(path), "%s/images/hud/%s", resource_dir, ICONS[i].file);
        Image img;
        if (!image_load_png(path, &img)) {
            fprintf(stderr, "HUD icon missing: %s\n", path);
            continue;
        }
        textures[i] = vkr_texture_create(img.w, img.h, img.px, false);
        image_free(&img);
    }
}

void hud_icons_free(void) {
    for (int i = 0; i < NICONS; i++) {
        vkr_texture_release(textures[i]);
        textures[i] = NULL;
    }
}

Texture *hud_icon(const char *key) {
    for (int i = 0; i < NICONS; i++)
        if (strcmp(ICONS[i].key, key) == 0) return textures[i];
    return NULL;
}
```

/* HUD components: one per element type (HUD_COMPONENTS), plus the panel, the target tab and the hotbar geometry.
 * They only draw what they are given; every size and colour comes from HUD_THEME. */
#include "draw.h"
#include "hud.h"

#include <math.h>
#include <stdio.h>
#include <string.h>

#define T (&HUD_THEME)

/* ---- helpers ---- */

static void round_rect(HudRect r, float radius, Color c) {
    if (r.w <= 0 || r.h <= 0) return;
    dr_fill_round_rect(r.x, r.y, r.w, r.h, radius * 2, radius * 2, c);
}

/* outline of a rounded rectangle: four edges and four quarter arcs (0 degrees = 3 o'clock, counter-clockwise) */
static void stroke_round_rect(HudRect r, float rad, float th, Color c) {
    float x0 = r.x, y0 = r.y, x1 = r.x + r.w, y1 = r.y + r.h, d = rad * 2;
    dr_line(x0 + rad, y0, x1 - rad, y0, th, c);
    dr_line(x0 + rad, y1, x1 - rad, y1, th, c);
    dr_line(x0, y0 + rad, x0, y1 - rad, th, c);
    dr_line(x1, y0 + rad, x1, y1 - rad, th, c);
    dr_stroke_arc(x0, y0, d, d, 90, 90, th, c);
    dr_stroke_arc(x1 - d, y0, d, d, 0, 90, th, c);
    dr_stroke_arc(x0, y1 - d, d, d, 180, 90, th, c);
    dr_stroke_arc(x1 - d, y1 - d, d, d, 270, 90, th, c);
}

static float baseline(FontStyle st, float size, HudRect r) {
    float a, d;
    dr_font_metrics(st, size, &a, &d);
    return r.y + (r.h + a - d) / 2;
}

static void text_centered(FontStyle st, float size, HudRect r, Color c, const char *s) {
    dr_text(st, size, r.x + (r.w - dr_text_width(st, size, s)) / 2, baseline(st, size, r), c, s);
}

static void text_left(FontStyle st, float size, float x, HudRect r, Color c, const char *s) {
    dr_text(st, size, x, baseline(st, size, r), c, s);
}

static void text_right(FontStyle st, float size, float right, HudRect r, Color c, const char *s) {
    dr_text(st, size, right - dr_text_width(st, size, s), baseline(st, size, r), c, s);
}

static float clampf(float v, float lo, float hi) { return v < lo ? lo : v > hi ? hi : v; }

/* ---- panel and tab ---- */

void hud_draw_panel(HudRect r, float s) {
    float rad = T->radius * s;
    for (int i = T->shadowLayers; i >= 1; i--) {
        float o = T->shadowStep * s * (float)i;
        round_rect((HudRect){ r.x - o, r.y - o / 2, r.w + 2 * o, r.h + 2 * o }, rad + o, T->shadow);
    }
    round_rect(r, rad, T->panel);
    stroke_round_rect(r, rad, fmaxf(1, s), T->border);
}

static void tab_text(const HudTarget *t, char *out, size_t cap) {
    if (t->extra[0]) snprintf(out, cap, "%s %s", t->name, t->extra);
    else snprintf(out, cap, "%s", t->name);
}

/* [pad][icon][pad][text][pad] and, with a close button, [close][pad] */
float hud_tab_width(const HudTarget *t, float s) {
    char text[2 * HUD_TEXT_MAX + 2];
    tab_text(t, text, sizeof(text));
    float w = (3 * T->tabPad + T->tabIcon) * s + dr_text_width(FONT_BOLD, T->font * s, text);
    return w + (t->canClose ? (T->closeSize + T->tabPad) * s : 0);
}

void hud_draw_tab(HudRect r, HudRect close, const HudTarget *t, const HudUiState *ui, float s) {
    if (!t->shown) return;
    hud_draw_panel(r, s);
    float x = r.x + T->tabPad * s, ic = T->tabIcon * s;
    Texture *icon = hud_icon("placeholder"); /* until characters have HUD icons */
    if (icon) dr_image(icon, x, r.y + (r.h - ic) / 2, ic, ic);
    x += ic + T->tabPad * s;
    char text[2 * HUD_TEXT_MAX + 2];
    tab_text(t, text, sizeof(text));
    text_left(FONT_BOLD, T->font * s, x, r, T->text, text);
    if (t->canClose) {
        Color c = ui->pressClose ? T->pressed : ui->hoverClose ? T->hover : T->textDim;
        float p = close.w * 0.28f, th = fmaxf(1.5f, 2 * s);
        dr_line(close.x + p, close.y + p, close.x + close.w - p, close.y + close.h - p, th, c);
        dr_line(close.x + close.w - p, close.y + p, close.x + p, close.y + close.h - p, th, c);
    }
}

/* ---- bar ---- */

static float bar_min_width(const HudElement *e, float s) { return T->barMinW * s; }
static float bar_height(const HudElement *e, float s) { return (e->thin ? T->thinBarH : T->barH) * s; }

static void bar_span(HudRect frame, float lo, float hi, bool two_sided, Color c) {
    lo = clampf(lo, two_sided ? -1 : 0, 1);
    hi = clampf(hi, two_sided ? -1 : 0, 1);
    if (hi > lo) dr_fill_rect(frame.x + lo * frame.w, frame.y, (hi - lo) * frame.w, frame.h, c);
}

static void bar_draw(const HudElement *e, HudRect r, const HudValue *v, const HudUiState *ui, int self, float s) {
    HudRect frame = r;
    if (e->two_sided) { /* left half: the zone below 0, right half: the frame (0..max) */
        frame.w = r.w / 2;
        frame.x = r.x + frame.w;
        dr_fill_rect(r.x, r.y, frame.w, r.h, T->dyingBg);
    }
    dr_fill_rect(frame.x, frame.y, frame.w, frame.h, T->barBg);
    float line = fmaxf(1, T->barFrameLine * s);
    if (!v) {
        dr_stroke_rect(frame.x, frame.y, frame.w, frame.h, line, T->emptyLine);
        return;
    }
    const HudBar *b = &v->bar;
    bar_span(frame, b->lightLo, b->lightHi, e->two_sided, T->accentLight[e->accent]);
    bar_span(frame, b->solidLo, b->solidHi, e->two_sided, T->accent[e->accent]);
    for (int i = 0; i < b->nmarkers && i < HUD_MAX_MARKERS; i++) {
        const HudMarker *m = &b->markers[i];
        if (m->at < (e->two_sided ? -1 : 0) || m->at > 1) continue;
        float mx = frame.x + m->at * frame.w;
        float over = m->style == HUD_MARK_TICK ? T->tickOverhang * s : 0;
        dr_line(mx, frame.y - over, mx, frame.y + frame.h + over, T->markerLine * s, T->marker);
    }
    dr_stroke_rect(frame.x, frame.y, frame.w, frame.h, line, T->barFrame);
    if (b->text[0]) text_centered(FONT_PLAIN, (e->thin ? T->smallFont : T->font) * s, frame, T->text, b->text);
}

/* ---- stat pill ---- */

static float pill_min_width(const HudElement *e, float s) { return T->pillW * s; }
static float pill_height(const HudElement *e, float s) { return T->pillH * s; }

static void pill_draw(const HudElement *e, HudRect r, const HudValue *v, const HudUiState *ui, int self, float s) {
    float rad = r.h / 2, edge = T->pillEdge * s;
    round_rect(r, rad, T->accent[e->accent]); /* shows as the coloured left edge */
    round_rect((HudRect){ r.x + edge, r.y, r.w - edge, r.h }, rad, T->slotBg);
    const char *label = v && v->pill.label[0] ? v->pill.label : e->label ? e->label : "";
    const char *value = v && v->pill.value[0] ? v->pill.value : "—";
    Color vc = v ? T->text : T->textDim;
    float pad = T->pillPad * s, x0 = r.x + edge + pad, x1 = r.x + r.w - pad;
    if (label[0]) {
        text_left(FONT_PLAIN, T->smallFont * s, x0, r, T->textDim, label);
        text_right(FONT_BOLD, T->font * s, x1, r, vc, value);
    } else {
        text_centered(FONT_BOLD, T->font * s, (HudRect){ x0, r.y, x1 - x0, r.h }, vc, value);
    }
}

/* ---- slider ---- */

static float slider_min_width(const HudElement *e, float s) { return (T->sliderLabelW + T->sliderMinW) * s; }
static float slider_height(const HudElement *e, float s) { return fmaxf(T->sliderKnob, T->font + 4) * s; }

/* the track starts after the label; half a knob of room at both ends */
static HudRect slider_track(HudRect r, float s) {
    float k = T->sliderKnob * s, th = T->sliderTrack * s;
    return (HudRect){ r.x + T->sliderLabelW * s + k / 2, r.y + (r.h - th) / 2, r.w - T->sliderLabelW * s - k, th };
}

static float slider_fraction(const HudSlider *sl) {
    return sl->max > sl->min ? clampf((float)(sl->value - sl->min) / (float)(sl->max - sl->min), 0, 1) : 0;
}

static void slider_draw(const HudElement *e, HudRect r, const HudValue *v, const HudUiState *ui, int self, float s) {
    const char *label = v && v->slider.label[0] ? v->slider.label : e->label ? e->label : "";
    char text[HUD_TEXT_MAX + 16];
    if (v) snprintf(text, sizeof(text), "%s %d", label, v->slider.value);
    else snprintf(text, sizeof(text), "%s", label);
    text_left(FONT_PLAIN, T->font * s, r.x, r, v ? T->text : T->textDim, text);
    HudRect tr = slider_track(r, s);
    round_rect(tr, tr.h / 2, T->barBg);
    if (!v) return;
    float f = slider_fraction(&v->slider), k = T->sliderKnob * s;
    round_rect((HudRect){ tr.x, tr.y, tr.w * f, tr.h }, tr.h / 2, T->accent[e->accent]);
    bool hot = ui->hover == self || ui->press == self;
    dr_fill_oval(tr.x + tr.w * f - k / 2, r.y + (r.h - k) / 2, k, k, hot ? T->hover : T->text);
}

static bool slider_mouse(const HudElement *e, HudRect r, HudValue *v, HudMouse m, HudUiState *ui, int self,
                         float s, HudEvent *ev) {
    if (!v || m.kind == HUD_MOUSE_UP || (m.kind == HUD_MOUSE_MOVE && ui->press != self)) return false;
    HudRect tr = slider_track(r, s);
    float f = tr.w > 0 ? clampf((m.x - tr.x) / tr.w, 0, 1) : 0;
    int val = v->slider.min + (int)lroundf(f * (float)(v->slider.max - v->slider.min));
    if (val == v->slider.value) return false;
    v->slider.value = val; /* drawn right away; the game publishes its own copy from the next frame on */
    ev->type = HUD_EV_SLIDER_CHANGED;
    ev->value = val;
    return true;
}

/* ---- hotbar ---- */

static float hotbar_min_width(const HudElement *e, float s) {
    return ((float)e->slots * T->slot + (float)(e->slots - 1) * T->slotGap) * s;
}
static float hotbar_height(const HudElement *e, float s) { return T->slot * s; }

HudRect hud_slot_rect(HudRect hotbar, int i, float s) {
    return (HudRect){ hotbar.x + (float)i * (T->slot + T->slotGap) * s, hotbar.y, T->slot * s, T->slot * s };
}

int hud_slot_at(const HudElement *e, HudRect hotbar, float x, float y, float s) {
    for (int i = 0; i < e->slots; i++)
        if (hud_rect_contains(hud_slot_rect(hotbar, i, s), x, y)) return i;
    return -1;
}

bool hud_slot_usable(const HudSlot *sl) { return sl->state == HUD_SLOT_AVAILABLE && sl->cooldown <= 0; }

static void hotbar_draw(const HudElement *e, HudRect r, const HudValue *v, const HudUiState *ui, int self, float s) {
    static const char *const KEYS[HUD_MAX_SLOTS] = { "1", "2", "3", "4", "5", "6", "7", "8", "9", "0" };
    float rad = T->slotRadius * s, line = fmaxf(1, s), pad = T->slotIconPad * s, tp = T->slotTextPad * s;
    float fs = T->smallFont * s, a, d;
    dr_font_metrics(FONT_PLAIN, fs, &a, &d);
    for (int i = 0; i < e->slots && i < HUD_MAX_SLOTS; i++) {
        const HudSlot *sl = v ? &v->slots[i] : NULL;
        HudSlotState st = sl ? sl->state : HUD_SLOT_EMPTY;
        bool used = st != HUD_SLOT_EMPTY;
        bool hover = used && ui->hover == self && ui->hoverSub == i;
        bool pressed = used && ui->press == self && ui->pressSub == i;
        HudRect sr = hud_slot_rect(r, i, s);
        if (hover && !pressed) sr.y -= s; /* raised */
        round_rect(sr, rad, T->slotBg);
        Texture *icon = used && sl->icon[0] ? hud_icon(sl->icon) : NULL;
        if (icon) {
            if (st == HUD_SLOT_UNAVAILABLE) dr_set_alpha(0.35f);
            dr_image(icon, sr.x + pad, sr.y + pad, sr.w - 2 * pad, sr.h - 2 * pad);
            dr_set_alpha(1);
        }
        if (st == HUD_SLOT_UNAVAILABLE) round_rect(sr, rad, T->veil);
        if (used && sl->cooldown > 0) {
            char cd[16];
            snprintf(cd, sizeof(cd), "%d", sl->cooldown);
            round_rect(sr, rad, T->veil);
            text_centered(FONT_BOLD, T->font * 1.3f * s, sr, T->text, cd);
        }
        Color border = pressed                   ? T->pressed
                       : hover                   ? T->hover
                       : st == HUD_SLOT_AVAILABLE ? T->accent[e->accent]
                                                 : T->emptyLine;
        stroke_round_rect(sr, rad, line, border);
        dr_text(FONT_PLAIN, fs, sr.x + tp, sr.y + tp + a, used ? T->text : T->textDim, KEYS[i]);
        if (used && sl->count > 0) {
            char cnt[16];
            snprintf(cnt, sizeof(cnt), "%d", sl->count);
            dr_text(FONT_BOLD, fs, sr.x + sr.w - tp - dr_text_width(FONT_BOLD, fs, cnt), sr.y + sr.h - tp - d,
                    T->text, cnt);
        }
    }
}

static bool hotbar_mouse(const HudElement *e, HudRect r, HudValue *v, HudMouse m, HudUiState *ui, int self,
                         float s, HudEvent *ev) {
    int at = hud_slot_at(e, r, m.x, m.y, s);
    switch (m.kind) {
    case HUD_MOUSE_DOWN:
        ui->pressSub = at;
        return false;
    case HUD_MOUSE_MOVE:
        if (ui->press != self) ui->hoverSub = at;
        return false;
    case HUD_MOUSE_UP:
        if (at < 0 || at != ui->pressSub || !v || !hud_slot_usable(&v->slots[at])) return false;
        ev->type = HUD_EV_SLOT_USED;
        ev->slot = at;
        return true;
    }
    return false;
}

/* ---- the component map: a new element type adds one entry ---- */

static const HudComponent BAR = { true, bar_min_width, bar_height, bar_draw, NULL };
static const HudComponent PILL = { false, pill_min_width, pill_height, pill_draw, NULL };
static const HudComponent SLIDER = { true, slider_min_width, slider_height, slider_draw, slider_mouse };
static const HudComponent HOTBAR = { false, hotbar_min_width, hotbar_height, hotbar_draw, hotbar_mouse };

const HudComponent *const HUD_COMPONENTS[HUD_ELEMENT_COUNT] = {
    [HUD_BAR] = &BAR,
    [HUD_PILL] = &PILL,
    [HUD_SLIDER] = &SLIDER,
    [HUD_HOTBAR] = &HOTBAR,
};

/* The HUD core: published values, the config check, the layout (cached), hit-testing, input and events.
 * No game state here; see hud.h for how the parts fit together. */
#include "hud.h"

#include <stdio.h>
#include <string.h>

static const HudRow *rows = HUD_ROWS;
static int nrows = -1; /* -1: HUD_NROWS (not a constant expression, so it can't initialise this) */

static int row_count(void) { return nrows < 0 ? HUD_NROWS : nrows; }

/* ---- config check ---- */

int hud_config_check(const HudRow *r, int n, char *err, size_t cap) {
    if (n < 1 || n > HUD_MAX_ROWS) {
        snprintf(err, cap, "%d rows (1 to %d)", n, HUD_MAX_ROWS);
        return -1;
    }
    int hotbars = 0;
    for (int i = 0; i < n; i++) {
        if (r[i].count < 1 || r[i].count > HUD_MAX_ROW_ELEMENTS) {
            snprintf(err, cap, "row %d has %d elements (1 to %d)", i + 1, r[i].count, HUD_MAX_ROW_ELEMENTS);
            return -1;
        }
        for (int k = 0; k < r[i].count; k++) {
            const HudElement *e = &r[i].elements[k];
            if ((int)e->type < 0 || e->type >= HUD_ELEMENT_COUNT || !HUD_COMPONENTS[e->type]) {
                snprintf(err, cap, "row %d element %d: unknown type", i + 1, k + 1);
                return -1;
            }
            if (!e->key || !e->key[0] || strlen(e->key) >= HUD_KEY_MAX) {
                snprintf(err, cap, "row %d element %d: key missing or longer than %d", i + 1, k + 1,
                         HUD_KEY_MAX - 1);
                return -1;
            }
            for (int pi = 0; pi <= i; pi++)
                for (int pk = 0; pk < (pi < i ? r[pi].count : k); pk++)
                    if (strcmp(r[pi].elements[pk].key, e->key) == 0) {
                        snprintf(err, cap, "key \"%s\" is used twice", e->key);
                        return -1;
                    }
            if (e->type == HUD_HOTBAR) {
                hotbars++;
                if (e->slots < 1 || e->slots > HUD_MAX_SLOTS) {
                    snprintf(err, cap, "hotbar \"%s\" has %d slots (1 to %d)", e->key, e->slots, HUD_MAX_SLOTS);
                    return -1;
                }
            }
        }
    }
    if (hotbars > 1) {
        snprintf(err, cap, "%d hotbars (at most one: it owns the number keys)", hotbars);
        return -1;
    }
    return 0;
}

/* ---- values ---- */

static HudValue values[HUD_MAX_VALUES];
static int nvalues;
static HudTarget target;

void hud_begin_frame(void) {
    nvalues = 0;
    memset(&target, 0, sizeof(target));
}

static HudValue *find_value(const char *key) {
    for (int i = 0; i < nvalues; i++)
        if (strcmp(values[i].key, key) == 0) return &values[i];
    return NULL;
}

const HudValue *hud_value(const char *key) { return find_value(key); }

/* The value under key with this type: the existing one, a cleared one if the type differs, or a new one. */
static HudValue *value_for(const char *key, HudElementType type) {
    HudValue *v = find_value(key);
    if (v && v->type == type) return v;
    if (!v) {
        if (nvalues == HUD_MAX_VALUES) return NULL;
        v = &values[nvalues++];
    }
    memset(v, 0, sizeof(*v));
    snprintf(v->key, sizeof(v->key), "%s", key);
    v->type = type;
    return v;
}

void hud_set_target(const char *name, const char *extra, bool can_close) {
    target.shown = true;
    snprintf(target.name, sizeof(target.name), "%s", name);
    snprintf(target.extra, sizeof(target.extra), "%s", extra ? extra : "");
    target.canClose = can_close;
}

const HudTarget *hud_target(void) { return &target; }

void hud_set_bar(const char *key, const HudBar *bar) {
    HudValue *v = value_for(key, HUD_BAR);
    if (v) v->bar = *bar;
}

void hud_set_pill(const char *key, const char *label, const char *value) {
    HudValue *v = value_for(key, HUD_PILL);
    if (!v) return;
    snprintf(v->pill.label, sizeof(v->pill.label), "%s", label);
    snprintf(v->pill.value, sizeof(v->pill.value), "%s", value);
}

void hud_set_slider(const char *key, const char *label, int value, int min, int max) {
    HudValue *v = value_for(key, HUD_SLIDER);
    if (!v) return;
    snprintf(v->slider.label, sizeof(v->slider.label), "%s", label);
    v->slider.value = value;
    v->slider.min = min;
    v->slider.max = max;
}

void hud_set_slot(const char *key, int index, const HudSlot *slot) {
    if (index < 0 || index >= HUD_MAX_SLOTS) return;
    HudValue *v = value_for(key, HUD_HOTBAR);
    if (v) v->slots[index] = *slot;
}

/* ---- screen, visibility and layout ---- */

static HudScreen screen = { 800, 600, 600, 0, 1 };
static bool visible = true;
static HudUiState ui = { -1, -1, -1, -1, false, false };
static bool pressActive; /* a left press started on the HUD and is still held */

typedef struct {
    bool valid;
    /* what it was computed from */
    const HudRow *rows;
    int nrows;
    HudScreen screen;
    HudTarget target;
    /* the result */
    float scale;
    HudRect panel, tab, close;
    HudRect elems[HUD_MAX_ROWS][HUD_MAX_ROW_ELEMENTS];
} Layout;

static Layout layout;
static int layout_count;

static void ui_reset(void) {
    ui = (HudUiState){ -1, -1, -1, -1, false, false };
    pressActive = false;
}

void hud_use_config(const HudRow *r, int n) {
    rows = r ? r : HUD_ROWS;
    nrows = r ? n : -1;
    layout.valid = false;
    ui_reset();
}

void hud_set_screen(const HudScreen *s) { screen = *s; }
bool hud_visible(void) { return visible; }

void hud_set_visible(bool on) {
    visible = on;
    ui_reset();
}

static const HudElement *element(int idx) {
    return &rows[idx / HUD_MAX_ROW_ELEMENTS].elements[idx % HUD_MAX_ROW_ELEMENTS];
}
static HudRect element_rect(int idx) {
    return layout.elems[idx / HUD_MAX_ROW_ELEMENTS][idx % HUD_MAX_ROW_ELEMENTS];
}
static const HudComponent *component(const HudElement *e) { return HUD_COMPONENTS[e->type]; }

static float row_min_width(const HudRow *row, float s) {
    float w = 0;
    for (int k = 0; k < row->count; k++) w += component(&row->elements[k])->min_width(&row->elements[k], s);
    return w + (float)(row->count - 1) * HUD_THEME.elemGap * s;
}

static float panel_width(float s) {
    float w = 0;
    for (int i = 0; i < row_count(); i++) {
        float rw = row_min_width(&rows[i], s);
        if (rw > w) w = rw;
    }
    return w + 2 * HUD_THEME.padding * s;
}

static void layout_compute(void) {
    const HudTheme *t = &HUD_THEME;
    int n = row_count();
    float s = screen.scale > 0 ? screen.scale : 1;
    float w = panel_width(s), avail = screen.winW - screen.left - 2 * t->margin * s;
    if (w > avail) { /* narrow window: shrink, but not below minScale */
        float s2 = avail > 0 ? s * avail / w : 0;
        s = s2 > s * t->minScale ? s2 : s * t->minScale;
        w = panel_width(s);
    }
    float inner = w - 2 * t->padding * s, h = 2 * t->padding * s, rowh[HUD_MAX_ROWS];
    for (int i = 0; i < n; i++) {
        rowh[i] = 0;
        for (int k = 0; k < rows[i].count; k++) {
            float eh = component(&rows[i].elements[k])->height(&rows[i].elements[k], s);
            if (eh > rowh[i]) rowh[i] = eh;
        }
        h += rowh[i] + (i > 0 ? t->rowGap * s : 0);
    }
    float x = (screen.winW - w) / 2;
    if (x < screen.left + t->margin * s) x = screen.left + t->margin * s;
    float y = screen.bottom - t->margin * s - h;
    layout.panel = (HudRect){ x, y, w, h };

    float ry = y + t->padding * s;
    for (int i = 0; i < n; i++) {
        const HudRow *row = &rows[i];
        float free = inner - row_min_width(row, s);
        int nflex = 0;
        for (int k = 0; k < row->count; k++) nflex += component(&row->elements[k])->flex;
        float ex = x + t->padding * s + (nflex == 0 ? free / 2 : 0); /* rows without flex elements are centred */
        for (int k = 0; k < row->count; k++) {
            const HudElement *e = &row->elements[k];
            const HudComponent *c = component(e);
            float ew = c->min_width(e, s) + (c->flex ? free / (float)nflex : 0), eh = c->height(e, s);
            layout.elems[i][k] = (HudRect){ ex, ry + (rowh[i] - eh) / 2, ew, eh };
            ex += ew + t->elemGap * s;
        }
        ry += rowh[i] + t->rowGap * s;
    }

    layout.tab = layout.close = (HudRect){ 0 };
    if (target.shown) {
        float tw = hud_tab_width(&target, s), th = t->tabH * s, cs = t->closeSize * s;
        layout.tab = (HudRect){ x + (w - tw) / 2, y - t->tabGap * s - th, tw, th };
        if (target.canClose)
            layout.close = (HudRect){ layout.tab.x + tw - t->tabPad * s - cs, layout.tab.y + (th - cs) / 2, cs, cs };
    }
    layout.scale = s;
    layout.rows = rows;
    layout.nrows = n;
    layout.screen = screen;
    layout.target = target;
    layout.valid = true;
    layout_count++;
}

static bool same_target(const HudTarget *a, const HudTarget *b) {
    return a->shown == b->shown && a->canClose == b->canClose && strcmp(a->name, b->name) == 0 &&
           strcmp(a->extra, b->extra) == 0;
}

/* Recomputes only when something the layout depends on changed. */
static void ensure_layout(void) {
    if (layout.valid && layout.rows == rows && layout.nrows == row_count() &&
        memcmp(&layout.screen, &screen, sizeof(screen)) == 0 && same_target(&layout.target, &target))
        return;
    layout_compute();
}

float hud_layout_scale(void) {
    ensure_layout();
    return layout.scale;
}

int hud_layout_count(void) { return layout_count; }

bool hud_part_rect(const char *part, HudRect *out) {
    if (!visible) return false;
    ensure_layout();
    if (strcmp(part, "panel") == 0) {
        *out = layout.panel;
        return true;
    }
    if (strcmp(part, "tab") == 0 || strcmp(part, "tab.close") == 0) {
        if (!target.shown || (part[3] == '.' && !target.canClose)) return false;
        *out = part[3] == '.' ? layout.close : layout.tab;
        return true;
    }
    for (int i = 0; i < row_count(); i++)
        for (int k = 0; k < rows[i].count; k++)
            if (strcmp(rows[i].elements[k].key, part) == 0) {
                *out = layout.elems[i][k];
                return true;
            }
    /* "<hotbar key>.<slot>" with slot 1..slots */
    const char *dot = strrchr(part, '.');
    if (!dot || !dot[1]) return false;
    char *end;

    if (*end) return false;

        for (int k = 0; k < rows[i].count; k++) {

                e->key[dot - part] != '\0')
                continue;
            if (slot < 1 || slot > e->slots) return false;
            *out = hud_slot_rect(layout.elems[i][k], (int)slot - 1, layout.scale);
            return true;
        }
    return false;
}

bool hud_contains(float x, float y) {
    if (!visible) return false;
    ensure_layout();
    return hud_rect_contains(layout.panel, x, y) || (target.shown && hud_rect_contains(layout.tab, x, y));

static void (*handler)(const HudEvent *ev);

void hud_set_event_handler(void (*fn)(const HudEvent *ev)) { handler = fn; }

static void send(const HudEvent *ev) {
    if (handler) handler(ev);

static int element_at(float x, float y) {
    for (int i = 0; i < row_count(); i++)
        for (int k = 0; k < rows[i].count; k++)
            if (hud_rect_contains(layout.elems[i][k], x, y)) return i * HUD_MAX_ROW_ELEMENTS + k;
    return -1;
}

static HudValue *element_value(const HudElement *e) {
    HudValue *v = find_value(e->key);
    return v && v->type == e->type ? v : NULL;
}

static void element_mouse(int idx, HudMouseKind kind, float x, float y) {
    const HudElement *e = element(idx);
    const HudComponent *c = component(e);
    if (!c->mouse) return;
    HudEvent ev = { 0 };
    if (c->mouse(e, element_rect(idx), element_value(e), (HudMouse){ kind, x, y }, &ui, idx, layout.scale, &ev)) {
        ev.key = e->key;
        send(&ev);
    }

bool hud_mouse_down(float x, float y) {
    if (!visible) return false;
    ensure_layout();
    ui.press = ui.pressSub = -1;
    if (target.shown && hud_rect_contains(layout.tab, x, y)) {
        ui.pressClose = target.canClose && hud_rect_contains(layout.close, x, y);
        pressActive = true;
        return true;
    }
    if (!hud_rect_contains(layout.panel, x, y)) return false;
    pressActive = true;
    ui.press = element_at(x, y);
    if (ui.press >= 0) element_mouse(ui.press, HUD_MOUSE_DOWN, x, y);
    return true;
}

bool hud_mouse_move(float x, float y) {
    if (!visible) return false;
    ensure_layout();
    if (pressActive) {
        if (ui.press >= 0) element_mouse(ui.press, HUD_MOUSE_MOVE, x, y);
        return true;
    }
    ui.hoverClose = target.shown && target.canClose && hud_rect_contains(layout.close, x, y);
    int idx = element_at(x, y);
    if (idx != ui.hover) {
        ui.hover = idx;
        ui.hoverSub = -1;
    }
    if (idx >= 0) element_mouse(idx, HUD_MOUSE_MOVE, x, y);
    return false;
}

bool hud_mouse_up(float x, float y) {
    if (!pressActive) return false;
    bool close = ui.pressClose;
    pressActive = false;
    ui.pressClose = false;
    if (visible) {
        ensure_layout();
        if (close && target.shown && target.canClose && hud_rect_contains(layout.close, x, y))
            send(&(HudEvent){ .type = HUD_EV_TARGET_CLOSED });
        if (ui.press >= 0) element_mouse(ui.press, HUD_MOUSE_UP, x, y);
    }
    ui.press = ui.pressSub = -1;
    return true;
}

bool hud_key(int slot) {
    if (!visible || slot < 0 || slot >= HUD_MAX_SLOTS) return false;
    for (int i = 0; i < row_count(); i++)

            send(&(HudEvent){ .type = HUD_EV_SLOT_USED, .key = e->key, .slot = slot });

bool hud_can_see(const Entity *e) {
    if (!e || e->type != ENTITY_CHARACTER) return false;
    if (!session_is_client()) return true;
    return e->owner[0] && strcasecmp(e->owner, session_my_name()) == 0;
}

Entity *hud_pick_character(int *others, bool *from_selection) {
    Entity *best = NULL;
    int n = 0;
    for (int i = 0; i < gh->selectedEntities.count; i++) {
        bool dup = false;
        for (int j = 0; j < i && !dup; j++) dup = gh->selectedEntities.items[j] == gh->selectedEntities.items[i];
        Entity *e = dup ? NULL : entity_by_id(gh->selectedEntities.items[i]);
        if (!hud_can_see(e)) continue;
        n++;
        if (!best || e->id < best->id) best = e;
    }
    *others = best ? n - 1 : 0;
    *from_selection = best != NULL;
    if (best || !session_is_client()) return best;
    for (int i = 0; i < gh->entities.count; i++) {
        Entity *e = gh->entities.items[i];
        if (hud_can_see(e) && (!best || e->id < best->id)) best = e;
    }
    return best;
}

static void publish_character(Entity *e, int others, bool from_selection, float dt, bool *moving) {
    char name[CHAR_NAME_MAX + 16], extra[HUD_TEXT_MAX] = "";
    entity_display_name(e, name, sizeof(name));
    bool dead = hp_stage(e->health, e->maxHealth) == HP_DEAD;
    bool tired = e->maxStamina > 0 && e->stamina <= 0;
    int n = others > 0 ? snprintf(extra, sizeof(extra), "+%d", others) : 0;
    if (dead || tired)
        snprintf(extra + n, sizeof(extra) - (size_t)n, "%s(%s)", n ? " " : "", dead ? "dead" : "exhausted");
    hud_set_target(name, extra, from_selection);

    /* bar animation: a character that wasn't shown in the previous frame starts without one */
    float hpf = bar_fraction(e->health, e->maxHealth), stf = bar_fraction(e->stamina, e->maxStamina);
    if (e->panelFrame != frame - 1) {
        bar_anim_reset(&e->hpAnim, hpf);
        bar_anim_reset(&e->staminaAnim, stf);
    }
    e->panelFrame = frame;
    if (bar_anim_step(&e->hpAnim, hpf, dt)) *moving = true;
    if (e->maxStamina <= 0) bar_anim_reset(&e->staminaAnim, stf); /* no bar: a new one appears at its value */
    else if (bar_anim_step(&e->staminaAnim, stf, dt)) *moving = true;

    HudBar hp = { 0 };
    bar_anim_spans(&e->hpAnim, &hp.solidLo, &hp.solidHi, &hp.lightLo, &hp.lightHi);
    HpBar layout = hp_bar_layout(e->health, e->maxHealth, 0, 1); /* in fractions of the frame */
    if (layout.lines) hp.markers[hp.nmarkers++] = (HudMarker){ layout.injured_x, HUD_MARK_LINE };
    if (layout.critical) hp.markers[hp.nmarkers++] = (HudMarker){ layout.critical_x, HUD_MARK_TICK };
    snprintf(hp.text, sizeof(hp.text), "%d/%d", e->health, e->maxHealth);
    hud_set_bar("hp", &hp);

    if (e->maxStamina > 0) {
        HudBar st = { 0 };
        bar_anim_spans(&e->staminaAnim, &st.solidLo, &st.solidHi, &st.lightLo, &st.lightHi);

bool hud_game_update(float dt) {
    frame++;
    refresh_screen();
    hud_begin_frame();
    if (!hud_visible()) return false;
    bool moving = false;
    int others;
    bool from_selection;
    Entity *e = hud_pick_character(&others, &from_selection);
    if (e) publish_character(e, others, from_selection, dt, &moving);
    publish_placeholders();
    return moving;
}

/* ---- events ---- */

static void on_event(const HudEvent *ev) {
    switch (ev->type) {
    case HUD_EV_TARGET_CLOSED: /* like a click on empty map */
        entities_clear_highlights();
        da_clear(&gh->selectedTiles);
        break;
    case HUD_EV_SLOT_USED: /* placeholder slots do nothing yet */
        if (gh->debugMode) console_log("HUD: slot %d used", ev->slot + 1);
        break;
    case HUD_EV_SLIDER_CHANGED:
        slider_value = ev->value;
        if (gh->debugMode) console_log("HUD: Value %d", ev->value);
        break;
    }
}

void hud_game_init(const char *resource_dir) {
    hud_icons_init(resource_dir);
    hud_set_event_handler(on_event);
}

void hud_game_shutdown(void) {
    hud_set_event_handler(NULL);
    hud_icons_free();
}

bool hud_game_key(SDL_Keycode key) {
    if (gh->console.active || gh->isCtrlDown || gh->isAltDown) return false;
    int slot = -1;
    if (key >= SDLK_1 && key <= SDLK_9) slot = (int)(key - SDLK_1);
    else if (key == SDLK_0) slot = 9;
    else if (key >= SDLK_KP_1 && key <= SDLK_KP_9) slot = (int)(key - SDLK_KP_1);
    else if (key == SDLK_KP_0) slot = 9;
    return slot >= 0 && hud_key(slot);
}
