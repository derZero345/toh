# Relay on the home server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `:host` works behind any router: the GM's game and the players connect out to a small relay (`toh-relay`) on the TrueNAS server, which pairs their connections and copies bytes.

**Architecture:** A shared wire format (`src/relaymsg.c`) for a handful of fixed `TOHR` messages; a single-threaded poll-loop relay (`relay/relay.c`, POSIX only) that links a player's socket with an "attach" socket the GM opens per player; `net.c` learns to host via a control connection (`net_host_relay`) and to join via the relay (`net_join_relay`), after which the existing encrypted `TOH1` protocol runs unchanged. Join code v2 carries only the secret; the room ID is a BLAKE2b hash of it, so the relay never sees the secret.

**Tech Stack:** C11, POSIX sockets + pthreads, libsodium (game side only), Make, bash e2e scripts, TrueNAS custom app (docker compose).

**Spec:** `docs/superpowers/specs/2026-11-24-relay-design.md`

`src/relaymsg.h`:

```c
#ifndef TOH_RELAYMSG_H
#define TOH_RELAYMSG_H

/*
 * Messages between the game and the relay (toh-relay), sent in plain bytes before the encrypted
 * TOH1 protocol starts. Every message is "TOHR" | u8 type | body; integers are little endian.
 *
 *   HOST    GM -> relay (control connection)   u8 version | 16 room
 *   JOIN    player -> relay                    u8 version | 16 room
 *   ATTACH  GM -> relay (one per player)       u8 version | 16 room | u32 ticket
 *   STATUS  relay -> any                       u8 status (RelayStatus)
 *   WAITING relay -> GM (control)              u32 ticket | u8 len | len bytes player address
 *   PING    both ways on the control connection, no body
 *
 * No dependencies (not even libsodium): the relay links this file too.
 * Design: docs/superpowers/specs/2026-11-24-relay-design.md, section 2.3.
 */

#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

#define RELAY_VERSION      1
#define RELAY_DEFAULT_PORT 41234
#define RELAY_ROOM_SIZE    16
#define RELAY_ADDR_MAX     64                       /* WAITING address, incl. the terminating NUL */
#define RELAY_MSG_MAX      (10 + RELAY_ADDR_MAX - 1) /* the longest message: WAITING */

typedef enum { RM_HOST = 1, RM_JOIN, RM_ATTACH, RM_STATUS, RM_WAITING, RM_PING } RelayMsgType;

typedef enum {
    RS_OK,
    RS_ROOM_TAKEN,
    RS_NO_ROOM,
    RS_FULL,
    RS_BAD_VERSION,
    RS_TIMEOUT,
    RS_BAD_REQUEST, /* the highest value */
} RelayStatus;

typedef struct {
    uint8_t type;                 /* RelayMsgType */
    uint8_t version;              /* HOST, JOIN, ATTACH */
    uint8_t room[RELAY_ROOM_SIZE]; /* HOST, JOIN, ATTACH */
    uint32_t ticket;              /* ATTACH, WAITING */
    uint8_t status;               /* STATUS */
    char addr[RELAY_ADDR_MAX];    /* WAITING: 1..63 printable ASCII characters, no spaces */
} RelayMsg;

/* Writes m to out. Returns its length, or 0 when m is invalid. */
size_t relaymsg_encode(const RelayMsg *m, uint8_t out[RELAY_MSG_MAX]);
/* Decodes the message at the start of buf. Returns the bytes it used (> 0), 0 when buf holds only the
 * beginning of a valid message, -1 when buf cannot start a valid message. Any version is accepted. */
int relaymsg_decode(const uint8_t *buf, size_t len, RelayMsg *out);

/* Splits "host", "host:port", "[v6]", "[v6]:port" or a bare IPv6 address. The port defaults to
 * RELAY_DEFAULT_PORT. False when s is malformed or host does not fit in cap. */
bool relay_parse_addr(const char *s, char *host, size_t cap, uint16_t *port);

#endif
```

```c
/* Tests for src/relaymsg.c (and, from task 3 on, relay/relay.c with raw sockets on localhost).
 * Run with `make test`. */
#include "relaymsg.h"

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static int failures, checks;

#define CHECK(cond) do {                                                       \
        checks++;                                                              \
        if (!(cond)) {                                                         \
            failures++;                                                        \
            fprintf(stderr, "%s:%d: CHECK failed: %s\n", __FILE__, __LINE__, #cond); \
        }                                                                      \
    } while (0)

/* ---- messages ------------------------------------------------------------------------------ */

static bool msg_equal(const RelayMsg *a, const RelayMsg *b) {
    return a->type == b->type && a->version == b->version && memcmp(a->room, b->room, RELAY_ROOM_SIZE) == 0 &&
           a->ticket == b->ticket && a->status == b->status && strcmp(a->addr, b->addr) == 0;
}

static void test_round_trip(void) {
    RelayMsg msgs[] = {
        { .type = RM_HOST, .version = RELAY_VERSION, .room = { 1, 2, 3, [15] = 16 } },
        { .type = RM_JOIN, .version = 7, .room = { 9 } },
        { .type = RM_ATTACH, .version = RELAY_VERSION, .room = { 5 }, .ticket = 0xA1B2C3D4u },
        { .type = RM_STATUS, .status = RS_TIMEOUT },
        { .type = RM_WAITING, .ticket = 42, .addr = "2001:db8::1" },
        { .type = RM_PING },
    };
    for (size_t i = 0; i < sizeof(msgs) / sizeof(msgs[0]); i++) {
        uint8_t buf[RELAY_MSG_MAX];
        size_t n = relaymsg_encode(&msgs[i], buf);
        CHECK(n >= 5 && n <= RELAY_MSG_MAX);
        RelayMsg d;
        CHECK(relaymsg_decode(buf, n, &d) == (int)n && msg_equal(&d, &msgs[i]));
        /* every shorter prefix asks for more bytes */
        for (size_t k = 0; k < n; k++) CHECK(relaymsg_decode(buf, k, &d) == 0);
        /* a second message behind it is left alone */
        uint8_t two[2 * RELAY_MSG_MAX];
        memcpy(two, buf, n);
        memcpy(two + n, buf, n);
        CHECK(relaymsg_decode(two, 2 * n, &d) == (int)n);
    }
    /* the longest address fits */
    RelayMsg w = { .type = RM_WAITING, .ticket = 1 };
    memset(w.addr, 'a', RELAY_ADDR_MAX - 1);
    uint8_t buf[RELAY_MSG_MAX];
    CHECK(relaymsg_encode(&w, buf) == RELAY_MSG_MAX);
}

static void test_rejects(void) {
    RelayMsg d;
    const uint8_t bad_magic[] = { 'T', 'O', 'H', 'X', RM_PING };
    CHECK(relaymsg_decode(bad_magic, sizeof(bad_magic), &d) == -1);
    CHECK(relaymsg_decode(bad_magic, 3, &d) == 0); /* "TOH" could still become "TOHR" */
    CHECK(relaymsg_decode((const uint8_t *)"GET / HTTP/1.1", 14, &d) == -1);
    const uint8_t bad_type[] = { 'T', 'O', 'H', 'R', 99 };
    CHECK(relaymsg_decode(bad_type, sizeof(bad_type), &d) == -1);
    const uint8_t bad_status[] = { 'T', 'O', 'H', 'R', RM_STATUS, RS_BAD_REQUEST + 1 };
    CHECK(relaymsg_decode(bad_status, sizeof(bad_status), &d) == -1);
    const uint8_t bad_addr[] = { 'T', 'O', 'H', 'R', RM_WAITING, 1, 0, 0, 0, 2, 'a', ' ' };
    CHECK(relaymsg_decode(bad_addr, sizeof(bad_addr), &d) == -1);
    const uint8_t empty_addr[] = { 'T', 'O', 'H', 'R', RM_WAITING, 1, 0, 0, 0, 0 };
    CHECK(relaymsg_decode(empty_addr, sizeof(empty_addr), &d) == -1);
    const uint8_t long_addr[] = { 'T', 'O', 'H', 'R', RM_WAITING, 1, 0, 0, 0, RELAY_ADDR_MAX };
    CHECK(relaymsg_decode(long_addr, sizeof(long_addr), &d) == -1);

    uint8_t buf[RELAY_MSG_MAX];
    RelayMsg m = { .type = RM_STATUS, .status = 200 };
    CHECK(relaymsg_encode(&m, buf) == 0);
    m = (RelayMsg){ .type = 0 };
    CHECK(relaymsg_encode(&m, buf) == 0);
    m = (RelayMsg){ .type = RM_WAITING, .addr = "two words" };
    CHECK(relaymsg_encode(&m, buf) == 0);
    m = (RelayMsg){ .type = RM_WAITING, .addr = "" };
    CHECK(relaymsg_encode(&m, buf) == 0);
}

static void test_parse_addr(void) {
    char host[64];
    uint16_t port;
    CHECK(relay_parse_addr("nas.example.net", host, sizeof(host), &port) && strcmp(host, "nas.example.net") == 0 &&
          port == RELAY_DEFAULT_PORT);
    CHECK(relay_parse_addr("127.0.0.1:5000", host, sizeof(host), &port) && strcmp(host, "127.0.0.1") == 0 &&
          port == 5000);
    CHECK(relay_parse_addr("[2001:db8::1]:41000", host, sizeof(host), &port) && strcmp(host, "2001:db8::1") == 0 &&
          port == 41000);
    CHECK(relay_parse_addr("[::1]", host, sizeof(host), &port) && strcmp(host, "::1") == 0 &&
          port == RELAY_DEFAULT_PORT);
    CHECK(relay_parse_addr("2001:db8::1", host, sizeof(host), &port) && strcmp(host, "2001:db8::1") == 0 &&
          port == RELAY_DEFAULT_PORT);
    CHECK(!relay_parse_addr("", host, sizeof(host), &port));
    CHECK(!relay_parse_addr("host:", host, sizeof(host), &port));
    CHECK(!relay_parse_addr("host:0", host, sizeof(host), &port));
    CHECK(!relay_parse_addr("host:65536", host, sizeof(host), &port));
    CHECK(!relay_parse_addr("host:12a", host, sizeof(host), &port));
    CHECK(!relay_parse_addr(":41234", host, sizeof(host), &port));
    CHECK(!relay_parse_addr("[]:1", host, sizeof(host), &port));
    CHECK(!relay_parse_addr("[::1]x", host, sizeof(host), &port));
    CHECK(!relay_parse_addr("averyverylonghostname", host, 8, &port));
}

    test_rejects();
    test_parse_addr();
    printf("%d checks, %d failed\n", checks, failures);
    return failures ? 1 : 0;
}
```

`src/relaymsg.c`:

```c
/* Relay messages: see relaymsg.h. */
#include "relaymsg.h"

#include <stdio.h>
#include <string.h>

static const uint8_t MAGIC[4] = { 'T', 'O', 'H', 'R' };

static void put_u32(uint8_t *p, uint32_t v) {
    p[0] = (uint8_t)v;
    p[1] = (uint8_t)(v >> 8);
    p[2] = (uint8_t)(v >> 16);
    p[3] = (uint8_t)(v >> 24);
}

static uint32_t get_u32(const uint8_t *p) {
    return (uint32_t)p[0] | (uint32_t)p[1] << 8 | (uint32_t)p[2] << 16 | (uint32_t)p[3] << 24;
}

static bool addr_ok(const char *s, size_t len) {
    if (len < 1 || len >= RELAY_ADDR_MAX) return false;
    for (size_t i = 0; i < len; i++)
        if (s[i] < 0x21 || s[i] > 0x7e) return false;
    return true;
}

size_t relaymsg_encode(const RelayMsg *m, uint8_t out[RELAY_MSG_MAX]) {
    memcpy(out, MAGIC, 4);
    size_t n = 4;
    out[n++] = m->type;
    switch (m->type) {
    case RM_HOST:
    case RM_JOIN:
    case RM_ATTACH:
        out[n++] = m->version;
        memcpy(out + n, m->room, RELAY_ROOM_SIZE);
        n += RELAY_ROOM_SIZE;
        if (m->type == RM_ATTACH) {
            put_u32(out + n, m->ticket);
            n += 4;
        }
        return n;
    case RM_STATUS:
        if (m->status > RS_BAD_REQUEST) return 0;
        out[n++] = m->status;
        return n;
    case RM_WAITING: {
        size_t len = strnlen(m->addr, RELAY_ADDR_MAX);
        if (!addr_ok(m->addr, len)) return 0;
        put_u32(out + n, m->ticket);
        n += 4;
        out[n++] = (uint8_t)len;
        memcpy(out + n, m->addr, len);
        return n + len;
    }
    case RM_PING:
        return n;
    default:
        return 0;
    }
}

int relaymsg_decode(const uint8_t *buf, size_t len, RelayMsg *out) {
    memset(out, 0, sizeof(*out));
    if (memcmp(buf, MAGIC, len < 4 ? len : 4) != 0) return -1;
    if (len < 5) return 0;
    uint8_t type = buf[4];
    size_t need;
    switch (type) {
    case RM_HOST:
    case RM_JOIN:   need = 5 + 1 + RELAY_ROOM_SIZE; break;
    case RM_ATTACH: need = 5 + 1 + RELAY_ROOM_SIZE + 4; break;
    case RM_STATUS: need = 6; break;
    case RM_PING:   need = 5; break;
    case RM_WAITING:
        if (len < 10) return 0;
        if (buf[9] == 0 || buf[9] >= RELAY_ADDR_MAX) return -1;
        need = 10 + buf[9];
        break;
    default:
        return -1;
    }
    if (len < need) return 0;
    const uint8_t *p = buf + 5;
    out->type = type;
    switch (type) {
    case RM_HOST:
    case RM_JOIN:
    case RM_ATTACH:
        out->version = p[0];
        memcpy(out->room, p + 1, RELAY_ROOM_SIZE);
        if (type == RM_ATTACH) out->ticket = get_u32(p + 1 + RELAY_ROOM_SIZE);
        break;
    case RM_STATUS:
        out->status = p[0];
        if (out->status > RS_BAD_REQUEST) return -1;
        break;
    case RM_WAITING:
        out->ticket = get_u32(p);
        memcpy(out->addr, p + 5, p[4]);
        out->addr[p[4]] = '\0';
        if (!addr_ok(out->addr, p[4])) return -1;
        break;
    }
    return (int)need;
}

static bool parse_port(const char *s, uint16_t *port) {
    if (!*s) return false;
    unsigned long v = 0;
    for (; *s; s++) {
        if (*s < '0' || *s > '9') return false;
        v = v * 10 + (unsigned long)(*s - '0');
        if (v > 65535) return false;
    }
    if (v == 0) return false;
    *port = (uint16_t)v;
    return true;
}

static bool copy_host(const char *s, size_t len, char *host, size_t cap) {
    if (len == 0 || len >= cap) return false;
    memcpy(host, s, len);
    host[len] = '\0';
    return true;
}

bool relay_parse_addr(const char *s, char *host, size_t cap, uint16_t *port) {
    *port = RELAY_DEFAULT_PORT;
    if (!s || !*s) return false;
    if (s[0] == '[') {
        const char *close = strchr(s, ']');
        if (!close || !copy_host(s + 1, (size_t)(close - s - 1), host, cap)) return false;
        if (close[1] == '\0') return true;
        return close[1] == ':' && parse_port(close + 2, port);
    }
    const char *colon = strchr(s, ':');
    if (colon && strchr(colon + 1, ':')) return copy_host(s, strlen(s), host, cap); /* bare IPv6 */
    if (!copy_host(s, colon ? (size_t)(colon - s) : strlen(s), host, cap)) return false;
    return !colon || parse_port(colon + 1, port);
}
```

```c
#ifndef TOH_RELAY_H
#define TOH_RELAY_H

/*
 * The relay (toh-relay): GMs and players both connect out to it, so the GM needs no open port.
 * A GM keeps a control connection (HOST) open for its room. A player sends JOIN; the relay tells
 * the GM (WAITING), the GM opens a new connection for that player (ATTACH), and the relay links
 * the two sockets and copies bytes both ways. Rooms are named by a hash of the session secret, so
 * the relay cannot read the (encrypted) game.
 * One thread with a poll loop; POSIX only (no SDL, no libsodium), so tests run it in-process.
 * Design: docs/superpowers/specs/2026-11-24-relay-design.md, section 2.
 */

#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

typedef struct {
    uint16_t port;     /* 0 = any free port */
    int max_rooms;     /* 64 */
    int max_players;   /* waiting or linked players per room: 32 */
    int max_sockets;   /* 1024 */
    int joins_per_min; /* JOINs per source address and minute: 5 */
    int first_msg_ms;  /* a new connection's first message: 5000 */
    int attach_ms;     /* a JOIN waits this long for the GM: 10000 */
    int ping_ms;       /* PING to each GM: 20000; a GM silent for 3 * ping_ms loses its room */
} RelayLimits;

typedef struct Relay Relay;

void relay_default_limits(RelayLimits *l);
/* Listens on IPv6 + IPv4 and starts the thread. log gets one line per event (NULL: quiet).
 * Returns NULL and fills err on failure. */
Relay *relay_start(const RelayLimits *l, FILE *log, char *err, size_t errcap);
uint16_t relay_port(const Relay *r);
/* Closes every connection and stops the thread. NULL is fine. */
void relay_stop(Relay *r);

#endif
```

```c
        return -1;

static void put(int fd, const RelayMsg *m) {

    size_t n = relaymsg_encode(m, buf);
    CHECK(n > 0 && send(fd, buf, n, MSG_NOSIGNAL) == (ssize_t)n);
}

/* Reads one message, byte by byte so nothing behind it is consumed. */
static bool get(int fd, RelayMsg *m, int ms) {
    uint8_t buf[RELAY_MSG_MAX];
    size_t n = 0;
    while (n < sizeof(buf)) {
        struct pollfd pf = { .fd = fd, .events = POLLIN };
        if (poll(&pf, 1, ms) <= 0 || recv(fd, buf + n, 1, 0) != 1) return false;
        int r = relaymsg_decode(buf, ++n, m);
        if (r > 0) return true;
        if (r < 0) return false;
    }
    return false;
}

static bool get_status(int fd, int status, int ms) {
    RelayMsg m;
    return get(fd, &m, ms) && m.type == RM_STATUS && m.status == status;
}

/* The relay closed fd within ms (whatever it still sent is skipped). */
static bool closed(int fd, int ms) {
    uint8_t b[256];
    for (;;) {
        struct pollfd pf = { .fd = fd, .events = POLLIN };
        if (poll(&pf, 1, ms) <= 0) return false;
        if (recv(fd, b, sizeof(b), 0) <= 0) return true;
    }
}

static bool recv_exact(int fd, void *p, size_t n, int ms) {
    size_t got = 0;
    while (got < n) {
        struct pollfd pf = { .fd = fd, .events = POLLIN };
        if (poll(&pf, 1, ms) <= 0) return false;
        ssize_t r = recv(fd, (char *)p + got, n - got, 0);
        if (r <= 0) return false;
        got += (size_t)r;
    }
    return true;
}
```

```c
#include "relay.h"
#include "relaymsg.h"

#include <arpa/inet.h>
#include <errno.h>
#include <fcntl.h>

#define LINK_BUF_MAX   (1u << 20) /* bytes buffered towards one side of a link */
#define CLOSE_FLUSH_MS 2000       /* a closing socket gets this long to send what it has */
#define RATE_SLOTS     256

enum { SK_NEW, SK_CONTROL, SK_WAITING, SK_LINKED, SK_CLOSING };

typedef struct Sock {
    int fd, kind;
    int room;          /* SK_CONTROL, SK_WAITING, linked player: room index; -1 = none */
    bool player;       /* SK_LINKED: the player's side (counts towards its room) */
    bool dead;         /* closed; freed at the start of the next loop iteration */
    uint32_t ticket;   /* SK_WAITING */
    uint64_t deadline; /* SK_NEW: first message; SK_WAITING: attach; SK_CLOSING: flush */
    uint64_t last_rx, next_ping; /* SK_CONTROL */
    struct Sock *peer; /* SK_LINKED */
    uint8_t in[RELAY_MSG_MAX];
    size_t in_len;
    uint8_t *out;
    size_t out_len, out_pos, out_cap;
    char addr[RELAY_ADDR_MAX];
} Sock;

typedef struct {
    bool used;
    uint8_t id[RELAY_ROOM_SIZE];
    Sock *control;
    int players;
} Room;

typedef struct {
    char addr[RELAY_ADDR_MAX];
    uint64_t start;
    int count;
} Rate;

struct Relay {
    RelayLimits lim;
    FILE *log;
    int lfd, wake_rd, wake_wr;
    uint16_t port;
    pthread_t thread;
    Sock **socks;
    int nsocks, cap;
    Room *rooms;
    int nrooms;
    Rate rate[RATE_SLOTS];
    uint32_t next_ticket;
};

static uint64_t now_ms(void) {
    struct timespec ts;
    clock_gettime(CLOCK_MONOTONIC, &ts);
    return (uint64_t)ts.tv_sec * 1000 + (uint64_t)ts.tv_nsec / 1000000;
}

static void set_nonblocking(int fd) {
    int fl = fcntl(fd, F_GETFL, 0);
    if (fl >= 0) fcntl(fd, F_SETFL, fl | O_NONBLOCK);
}

static void rlog(Relay *r, const char *fmt, ...) {
    if (!r->log) return;
    va_list ap;
    va_start(ap, fmt);
    vfprintf(r->log, fmt, ap);
    va_end(ap);
    fputc('\n', r->log);
    fflush(r->log);
}

/* ---- sockets ------------------------------------------------------------------------------- */

static size_t out_pending(const Sock *s) { return s->out_len - s->out_pos; }

static bool out_append(Sock *s, const void *p, size_t len) {
    if (s->out_pos > 0 && s->out_pos == s->out_len) s->out_pos = s->out_len = 0;
    if (len > s->out_cap - s->out_len) {
        if (s->out_pos > 0) { /* compact first */
            memmove(s->out, s->out + s->out_pos, s->out_len - s->out_pos);
            s->out_len -= s->out_pos;
            s->out_pos = 0;
        }
        if (len > s->out_cap - s->out_len) {
            size_t cap = s->out_cap ? s->out_cap : 4096;
            while (cap - s->out_len < len) cap *= 2;
            uint8_t *np = realloc(s->out, cap);
            if (!np) return false;
            s->out = np;
            s->out_cap = cap;
        }
    }
    memcpy(s->out + s->out_len, p, len);
    s->out_len += len;
    return true;
}

static void out_msg(Sock *s, const RelayMsg *m) {
    uint8_t buf[RELAY_MSG_MAX];
    size_t n = relaymsg_encode(m, buf);
    if (n) out_append(s, buf, n);
}

static Sock *sock_new(Relay *r, int fd, const char *addr) {
    if (r->nsocks == r->cap) {
        int cap = r->cap ? r->cap * 2 : 64;
        Sock **ns = realloc(r->socks, (size_t)cap * sizeof(*ns));
        if (!ns) return NULL;
        r->socks = ns;
        r->cap = cap;
    }
    Sock *s = calloc(1, sizeof(*s));
    if (!s) return NULL;
    s->fd = fd;
    s->kind = SK_NEW;
    s->room = -1;
    s->deadline = now_ms() + (uint64_t)r->lim.first_msg_ms;
    snprintf(s->addr, sizeof(s->addr), "%s", addr);
    int one = 1;
    setsockopt(fd, IPPROTO_TCP, TCP_NODELAY, &one, sizeof(one));
    set_nonblocking(fd);
    r->socks[r->nsocks++] = s;
    return s;
}

static void room_end(Relay *r, int idx);

/* Gives back what s holds in its room: a player slot, or the whole room for a control connection. */
static void release(Relay *r, Sock *s) {
    int idx = s->room;
    s->room = -1;
    if (idx < 0 || !r->rooms[idx].used) return;
    if (s->kind == SK_CONTROL) room_end(r, idx);
    else if (s->kind == SK_WAITING || (s->kind == SK_LINKED && s->player)) r->rooms[idx].players--;
}

/* Closes s now. Its link partner sends what it still has buffered, then closes too. */
static void sock_close(Relay *r, Sock *s) {
    if (s->dead) return;
    release(r, s);
    s->dead = true;
    close(s->fd);
    Sock *p = s->peer;
    s->peer = NULL;
    if (p) {
        p->peer = NULL;
        if (!p->dead) {
            release(r, p);
            p->kind = SK_CLOSING;
            p->deadline = now_ms() + CLOSE_FLUSH_MS;
        }
    }
}

/* Answers s with an error status, then closes it once the answer is out. */
static void fail(Relay *r, Sock *s, int status) {
    release(r, s);
    RelayMsg m = { .type = RM_STATUS, .status = (uint8_t)status };
    out_msg(s, &m);
    s->kind = SK_CLOSING;
    s->in_len = 0;
    s->deadline = now_ms() + CLOSE_FLUSH_MS;
}

static void room_end(Relay *r, int idx) {
    r->rooms[idx].used = false;
    r->rooms[idx].control = NULL;
    r->nrooms--;
    for (int i = 0; i < r->nsocks; i++) {
        Sock *s = r->socks[i];
        if (s->dead || s->room != idx) continue;
        if (s->kind == SK_WAITING) fail(r, s, RS_NO_ROOM);
        else s->room = -1; /* linked players stay linked */
    }
    rlog(r, "room closed (%d open)", r->nrooms);
}

static int room_find(Relay *r, const uint8_t id[RELAY_ROOM_SIZE]) {
    for (int i = 0; i < r->lim.max_rooms; i++)
        if (r->rooms[i].used && memcmp(r->rooms[i].id, id, RELAY_ROOM_SIZE) == 0) return i;
    return -1;
}

/* At most joins_per_min JOINs per address and minute. */
static bool rate_ok(Relay *r, const char *addr) {
    uint64_t now = now_ms();
    Rate *free_slot = NULL, *oldest = &r->rate[0];
    for (int i = 0; i < RATE_SLOTS; i++) {
        Rate *s = &r->rate[i];
        if (s->addr[0] && strcmp(s->addr, addr) == 0) {
            if (now - s->start >= 60000) {
                s->start = now;
                s->count = 0;
            }
            return ++s->count <= r->lim.joins_per_min;
        }
        if (!s->addr[0] || now - s->start >= 60000) free_slot = s;
        if (s->start < oldest->start) oldest = s;
    }
    Rate *s = free_slot ? free_slot : oldest;
    snprintf(s->addr, sizeof(s->addr), "%s", addr);
    s->start = now;
    s->count = 1;
    return s->count <= r->lim.joins_per_min;
}

/* ---- messages ------------------------------------------------------------------------------ */

static void on_host(Relay *r, Sock *s, const RelayMsg *m) {
    if (room_find(r, m->room) >= 0) {
        fail(r, s, RS_ROOM_TAKEN);
        return;
    }
    int idx = -1;
    for (int i = 0; i < r->lim.max_rooms && idx < 0; i++)
        if (!r->rooms[i].used) idx = i;
    if (idx < 0) {
        rlog(r, "%s: no free room", s->addr);
        fail(r, s, RS_FULL);
        return;
    }
    r->rooms[idx] = (Room){ .used = true, .control = s };
    memcpy(r->rooms[idx].id, m->room, RELAY_ROOM_SIZE);
    r->nrooms++;
    uint64_t now = now_ms();
    s->kind = SK_CONTROL;
    s->room = idx;
    s->deadline = 0;
    s->last_rx = now;
    s->next_ping = now + (uint64_t)r->lim.ping_ms;
    RelayMsg ok = { .type = RM_STATUS, .status = RS_OK };
    out_msg(s, &ok);
    rlog(r, "%s opened a room (%d open)", s->addr, r->nrooms);
}

static void on_join(Relay *r, Sock *s, const RelayMsg *m) {
    if (!rate_ok(r, s->addr)) {
        rlog(r, "%s: too many joins", s->addr);
        fail(r, s, RS_FULL);
        return;
    }
    int idx = room_find(r, m->room);
    if (idx < 0) {
        fail(r, s, RS_NO_ROOM);
        return;
    }
    Room *room = &r->rooms[idx];
    if (room->players >= r->lim.max_players) {
        fail(r, s, RS_FULL);
        return;
    }
    if (++r->next_ticket == 0) r->next_ticket = 1;
    room->players++;
    s->kind = SK_WAITING;
    s->room = idx;
    s->ticket = r->next_ticket;
    s->deadline = now_ms() + (uint64_t)r->lim.attach_ms;
    RelayMsg w = { .type = RM_WAITING, .ticket = s->ticket };
    snprintf(w.addr, sizeof(w.addr), "%s", s->addr);
    out_msg(room->control, &w);
    rlog(r, "%s is waiting for its GM", s->addr);
}

static void on_attach(Relay *r, Sock *s, const RelayMsg *m) {
    int idx = room_find(r, m->room);
    Sock *w = NULL;
    for (int i = 0; idx >= 0 && i < r->nsocks && !w; i++) {
        Sock *t = r->socks[i];
        if (!t->dead && t->kind == SK_WAITING && t->room == idx && t->ticket == m->ticket) w = t;
    }
    if (!w) {
        fail(r, s, RS_NO_ROOM);
        return;
    }
    RelayMsg ok = { .type = RM_STATUS, .status = RS_OK };
    out_msg(w, &ok);
    out_msg(s, &ok);
    w->kind = SK_LINKED;
    w->player = true;
    w->deadline = 0;
    s->kind = SK_LINKED;
    s->deadline = 0;
    w->peer = s;
    s->peer = w;
    rlog(r, "%s linked", w->addr);
}

static void on_message(Relay *r, Sock *s, const RelayMsg *m) {
    if (s->kind == SK_CONTROL) {
        if (m->type != RM_PING) sock_close(r, s); /* a PING only refreshes last_rx */
        return;
    }
    if (s->kind != SK_NEW || (m->type != RM_HOST && m->type != RM_JOIN && m->type != RM_ATTACH)) {
        fail(r, s, RS_BAD_REQUEST);
        return;
    }
    if (m->version != RELAY_VERSION) {
        fail(r, s, RS_BAD_VERSION);
        return;
    }
    if (m->type == RM_HOST) on_host(r, s, m);
    else if (m->type == RM_JOIN) on_join(r, s, m);
    else on_attach(r, s, m);
}

/* ---- I/O ----------------------------------------------------------------------------------- */

static void do_read(Relay *r, Sock *s) {
    uint8_t buf[65536];
    for (;;) {
        if (s->dead) return;
        if (s->kind == SK_LINKED && s->peer && out_pending(s->peer) >= LINK_BUF_MAX) return; /* partner is slow */
        bool raw = s->kind == SK_LINKED || s->kind == SK_CLOSING;
        uint8_t *dst = raw ? buf : s->in + s->in_len;
        size_t cap = raw ? sizeof(buf) : sizeof(s->in) - s->in_len;
        ssize_t n = recv(s->fd, dst, cap, 0);
        if (n < 0 && errno == EINTR) continue;
        if (n < 0 && (errno == EAGAIN || errno == EWOULDBLOCK)) return;
        if (n <= 0) {
            sock_close(r, s);
            return;
        }
        if (s->kind == SK_CLOSING) continue; /* nobody wants it */
        if (s->kind == SK_LINKED) {
            if (s->peer && !out_append(s->peer, buf, (size_t)n)) sock_close(r, s);
            continue;
        }
        s->in_len += (size_t)n;
        if (s->kind == SK_CONTROL) s->last_rx = now_ms();
        while (!s->dead && s->in_len > 0 && (s->kind == SK_NEW || s->kind == SK_CONTROL || s->kind == SK_WAITING)) {
            RelayMsg m;
            int used = relaymsg_decode(s->in, s->in_len, &m);
            if (used == 0 && s->in_len < sizeof(s->in)) break;
            if (used <= 0) {
                if (s->kind == SK_CONTROL) sock_close(r, s);
                else fail(r, s, RS_BAD_REQUEST);
                break;
            }
            memmove(s->in, s->in + used, s->in_len - (size_t)used);
            s->in_len -= (size_t)used;
            on_message(r, s, &m);
        }
        if (s->kind == SK_LINKED && s->in_len > 0) { /* bytes that came right behind ATTACH */
            if (s->peer) out_append(s->peer, s->in, s->in_len);
            s->in_len = 0;
        }
    }
}

static void do_write(Relay *r, Sock *s) {
    while (out_pending(s) > 0) {
        ssize_t n = send(s->fd, s->out + s->out_pos, out_pending(s), MSG_NOSIGNAL);
        if (n > 0) {
            s->out_pos += (size_t)n;
            continue;
        }
        if (n < 0 && errno == EINTR) continue;
        if (n < 0 && (errno == EAGAIN || errno == EWOULDBLOCK)) return;
        sock_close(r, s);
        return;
    }
    s->out_pos = s->out_len = 0;
    if (s->kind == SK_CLOSING) sock_close(r, s);
}

static void addr_text(const struct sockaddr_storage *sa, char *out, size_t cap) {
    char ip[INET6_ADDRSTRLEN] = "?";
    if (sa->ss_family == AF_INET) {
        inet_ntop(AF_INET, &((const struct sockaddr_in *)sa)->sin_addr, ip, sizeof(ip));
    } else if (sa->ss_family == AF_INET6) {
        const struct in6_addr *a = &((const struct sockaddr_in6 *)sa)->sin6_addr;
        if (IN6_IS_ADDR_V4MAPPED(a)) inet_ntop(AF_INET, a->s6_addr + 12, ip, sizeof(ip));
        else inet_ntop(AF_INET6, a, ip, sizeof(ip));
    }
    snprintf(out, cap, "%s", ip);
}

static void accept_all(Relay *r) {
    for (;;) {
        struct sockaddr_storage sa;
        socklen_t sl = sizeof(sa);
        int fd = accept(r->lfd, (struct sockaddr *)&sa, &sl);
        if (fd < 0) return;
        if (r->nsocks >= r->lim.max_sockets) {
            close(fd);
            continue;
        }
        char addr[RELAY_ADDR_MAX];
        addr_text(&sa, addr, sizeof(addr));
        if (!sock_new(r, fd, addr)) close(fd);
    }
}

/* ---- the thread ---------------------------------------------------------------------------- */

static void timers(Relay *r, uint64_t now) {
    for (int i = 0; i < r->nsocks; i++) {
        Sock *s = r->socks[i];
        if (s->dead) continue;
        if (s->kind == SK_CLOSING) {
            if (out_pending(s) == 0 || now >= s->deadline) sock_close(r, s);
        } else if (s->kind == SK_NEW && now >= s->deadline) {
            fail(r, s, RS_BAD_REQUEST);
        } else if (s->kind == SK_WAITING && now >= s->deadline) {
            rlog(r, "%s: the GM did not attach", s->addr);
            fail(r, s, RS_TIMEOUT);
        } else if (s->kind == SK_CONTROL) {
            if (now - s->last_rx >= 3 * (uint64_t)r->lim.ping_ms) {
                rlog(r, "%s: the GM stopped answering", s->addr);
                sock_close(r, s);
            } else if (now >= s->next_ping) {
                RelayMsg ping = { .type = RM_PING };
                out_msg(s, &ping);
                s->next_ping = now + (uint64_t)r->lim.ping_ms;
            }
        }
    }
}

/* Milliseconds until timers has something to do. */
static int next_timeout(Relay *r, uint64_t now) {
    uint64_t best = now + 1000;
    for (int i = 0; i < r->nsocks; i++) {
        Sock *s = r->socks[i];
        uint64_t t = 0;
        if (s->kind == SK_CONTROL) {
            uint64_t dead = s->last_rx + 3 * (uint64_t)r->lim.ping_ms;
            t = s->next_ping < dead ? s->next_ping : dead;
        } else if (s->deadline) {
            t = s->deadline;
        }
        if (t && t < best) best = t;
    }
    return best > now ? (int)(best - now) : 0;
}

static void sweep(Relay *r) {
    int j = 0;
    for (int i = 0; i < r->nsocks; i++) {
        Sock *s = r->socks[i];
        if (s->dead) {
            free(s->out);
            free(s);
        } else {
            r->socks[j++] = s;
        }
    }
    r->nsocks = j;
}

static void *thread_main(void *arg) {
    Relay *r = arg;
    struct pollfd *pf = NULL;
    Sock **pc = NULL;
    int pcap = 0;
    for (;;) {
        uint64_t now = now_ms();
        timers(r, now);
        sweep(r);
        if (r->nsocks + 2 > pcap) {
            pcap = (r->nsocks + 2) * 2;
            pf = realloc(pf, (size_t)pcap * sizeof(*pf));
            pc = realloc(pc, (size_t)pcap * sizeof(*pc));
            if (!pf || !pc) abort();
        }
        int np = 0;
        pf[np] = (struct pollfd){ .fd = r->wake_rd, .events = POLLIN };
        pc[np++] = NULL;
        pf[np] = (struct pollfd){ .fd = r->lfd, .events = POLLIN };
        pc[np++] = NULL;
        for (int i = 0; i < r->nsocks; i++) {
            Sock *s = r->socks[i];
            short ev = POLLIN;
            if (s->kind == SK_LINKED && s->peer && out_pending(s->peer) >= LINK_BUF_MAX) ev = 0;
            if (out_pending(s)) ev |= POLLOUT;
            pf[np] = (struct pollfd){ .fd = s->fd, .events = ev };
            pc[np++] = s;
        }
        if (poll(pf, (nfds_t)np, next_timeout(r, now)) < 0 && errno != EINTR) break;
        if (pf[0].revents) break; /* relay_stop */
        if (pf[1].revents) accept_all(r);
        for (int i = 2; i < np; i++) {
            Sock *s = pc[i];
            short rev = pf[i].revents;
            if (s->dead || !rev) continue;
            if ((rev & (POLLHUP | POLLERR)) && !(pf[i].events & POLLIN)) { /* gone while back-pressured */
                sock_close(r, s);
                continue;
            }
            if (rev & (POLLIN | POLLHUP | POLLERR)) do_read(r, s);
            if (!s->dead && (rev & POLLOUT)) do_write(r, s);
        }
    }
    free(pf);
    free(pc);
    return NULL;
}

/* ---- public API ---------------------------------------------------------------------------- */

void relay_default_limits(RelayLimits *l) {
    *l = (RelayLimits){ .port = RELAY_DEFAULT_PORT, .max_rooms = 64, .max_players = 32, .max_sockets = 1024,
                        .joins_per_min = 5, .first_msg_ms = 5000, .attach_ms = 10000, .ping_ms = 20000 };
}

static int listen_socket(uint16_t port, char *err, size_t errcap) {
    /* dual stack first, plain IPv4 when the machine has no IPv6 */
    int fd = socket(AF_INET6, SOCK_STREAM, 0);
    if (fd >= 0) {
        int zero = 0, one = 1;
        setsockopt(fd, IPPROTO_IPV6, IPV6_V6ONLY, &zero, sizeof(zero));
        setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &one, sizeof(one));
        struct sockaddr_in6 sa = { .sin6_family = AF_INET6, .sin6_port = htons(port), .sin6_addr = IN6ADDR_ANY_INIT };
        if (bind(fd, (struct sockaddr *)&sa, sizeof(sa)) == 0 && listen(fd, 64) == 0) return fd;
        close(fd);
    }
    fd = socket(AF_INET, SOCK_STREAM, 0);
    if (fd >= 0) {
        int one = 1;
        setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &one, sizeof(one));
        struct sockaddr_in sa = { .sin_family = AF_INET, .sin_port = htons(port) };
        sa.sin_addr.s_addr = htonl(INADDR_ANY);
        if (bind(fd, (struct sockaddr *)&sa, sizeof(sa)) == 0 && listen(fd, 64) == 0) return fd;
        snprintf(err, errcap, "port %u: %s", port, strerror(errno));
        close(fd);
        return -1;
    }
    snprintf(err, errcap, "%s", strerror(errno));
    return -1;
}

Relay *relay_start(const RelayLimits *l, FILE *log, char *err, size_t errcap) {
    Relay *r = calloc(1, sizeof(*r));
    int fds[2] = { -1, -1 };
    if (!r || !(r->rooms = calloc((size_t)l->max_rooms, sizeof(*r->rooms))) || pipe(fds) != 0) {
        snprintf(err, errcap, "out of memory");
        if (r) free(r->rooms);
        free(r);
        return NULL;
    }
    r->lim = *l;
    r->log = log;
    r->wake_rd = fds[0];
    r->wake_wr = fds[1];
    r->lfd = listen_socket(l->port, err, errcap);
    if (r->lfd < 0) {
        close(fds[0]);
        close(fds[1]);
        free(r->rooms);
        free(r);
        return NULL;
    }
    set_nonblocking(r->lfd);
    struct sockaddr_storage sa;
    socklen_t sl = sizeof(sa);
    getsockname(r->lfd, (struct sockaddr *)&sa, &sl);
    r->port = ntohs(sa.ss_family == AF_INET6 ? ((struct sockaddr_in6 *)&sa)->sin6_port
                                             : ((struct sockaddr_in *)&sa)->sin_port);
    rlog(r, "listening on port %u", r->port);
    if (pthread_create(&r->thread, NULL, thread_main, r) != 0) {
        snprintf(err, errcap, "could not start the relay thread");
        close(r->lfd);
        close(fds[0]);
        close(fds[1]);
        free(r->rooms);
        free(r);
        return NULL;
    }
    return r;
}

uint16_t relay_port(const Relay *r) { return r ? r->port : 0; }

void relay_stop(Relay *r) {
    if (!r) return;
    char c = 1;
    if (write(r->wake_wr, &c, 1) < 0) { /* the thread is gone already */ }
    pthread_join(r->thread, NULL);
    for (int i = 0; i < r->nsocks; i++) {
        if (!r->socks[i]->dead) close(r->socks[i]->fd);
        free(r->socks[i]->out);
        free(r->socks[i]);
    }
    free(r->socks);
    free(r->rooms);
    close(r->lfd);
    close(r->wake_rd);
    close(r->wake_wr);
    free(r);
}
```

```c
/* Tries one address; returns the connected (non-blocking) socket or -1. */
static int try_connect_sa(Net *n, const struct sockaddr_storage *ss, socklen_t sl) {
    int fd = socket(ss->ss_family, SOCK_STREAM, 0);
    if (fd < 0) return -1;
    set_nonblocking(fd);
    if (connect(fd, (const struct sockaddr *)ss, sl) == 0) return fd;
    if (errno != EINPROGRESS) {
        close(fd);
        return -1;
    }
    uint64_t end = now_ms() + NET_CONNECT_TIMEOUT_MS;
    for (;;) {
        uint64_t now = now_ms();
        if (now >= end || stop_requested(n)) break;
        struct pollfd pf[2] = { { .fd = fd, .events = POLLOUT }, { .fd = n->wake_rd, .events = POLLIN } };
        int r = poll(pf, 2, (int)(end - now));
        if (r < 0 && errno != EINTR) break;
        if (pf[1].revents) {
            char buf[64];
            while (read(n->wake_rd, buf, sizeof(buf)) > 0) {}
        }
        if (pf[0].revents) {
            int err = 0;
            socklen_t el = sizeof(err);
            if (getsockopt(fd, SOL_SOCKET, SO_ERROR, &err, &el) == 0 && err == 0) return fd;
            break;
        }
    }
    close(fd);
    return -1;
}

static int try_connect(Net *n, const NetAddr *a, uint16_t port) {
    struct sockaddr_storage ss;
    memset(&ss, 0, sizeof(ss));
    socklen_t sl;
    if (a->family == 4) {
        struct sockaddr_in *s4 = (struct sockaddr_in *)&ss;
        s4->sin_family = AF_INET;
        s4->sin_port = htons(port);
        memcpy(&s4->sin_addr, a->addr, 4);
        sl = sizeof(*s4);
    } else {
        struct sockaddr_in6 *s6 = (struct sockaddr_in6 *)&ss;
        s6->sin6_family = AF_INET6;
        s6->sin6_port = htons(port);
        memcpy(&s6->sin6_addr, a->addr, 16);
        sl = sizeof(*s6);
    }
    return try_connect_sa(n, &ss, sl);
}

/* Connects to the first relay address that answers (IPv6 first). Returns the socket or -1;
 * sa / sl (may be NULL) get the address. */
static int relay_connect(Net *n, struct sockaddr_storage *sa, socklen_t *sl) {
    char host[NET_RELAY_ADDR_MAX], port[8];
    uint16_t p;
    if (!relay_parse_addr(n->relay_addr, host, sizeof(host), &p)) return -1;
    snprintf(port, sizeof(port), "%u", p);
    struct addrinfo hints = { .ai_socktype = SOCK_STREAM }, *res;
    if (getaddrinfo(host, port, &hints, &res) != 0) return -1;
    int fd = -1;
    for (int pass = 0; pass < 2 && fd < 0; pass++) {
        for (struct addrinfo *a = res; a && fd < 0 && !stop_requested(n); a = a->ai_next) {
            if (a->ai_family != (pass == 0 ? AF_INET6 : AF_INET)) continue;
            struct sockaddr_storage ss;
            memset(&ss, 0, sizeof(ss));
            memcpy(&ss, a->ai_addr, a->ai_addrlen);
            fd = try_connect_sa(n, &ss, a->ai_addrlen);
            if (fd >= 0 && sa) {
                *sa = ss;
                *sl = a->ai_addrlen;
            }
        }
    }
    freeaddrinfo(res);
    return fd;
}
```

```c
static void ctl_attach(Net *n, const RelayMsg *w) {

static void ctl_read(Net *n) {
    for (;;) {
        ssize_t r = recv(n->cfd, n->cin + n->cin_len, sizeof(n->cin) - n->cin_len, 0);
        if (r < 0 && errno == EINTR) continue;
        if (r < 0 && (errno == EAGAIN || errno == EWOULDBLOCK)) return;
        if (r <= 0) {
            ctl_down(n, NET_END_LOST);
            return;
        }
        n->cin_len += (size_t)r;
        n->clast_rx = now_ms();
        for (;;) {
            RelayMsg m;
            int used = relaymsg_decode(n->cin, n->cin_len, &m);
            if (used == 0 && n->cin_len < sizeof(n->cin)) break;
            if (used <= 0) {
                ctl_down(n, NET_END_BAD_DATA);
                return;
            }
            memmove(n->cin, n->cin + used, n->cin_len - (size_t)used);
            n->cin_len -= (size_t)used;
            if (n->cstate == CTL_HELLO) {
                if (m.type != RM_STATUS) {
                    ctl_down(n, NET_END_BAD_DATA);
                    return;
                }
                if (m.status != RS_OK) {
                    ctl_down(n, status_end(m.status));
                    return;
                }
                n->cstate = CTL_UP;
                n->cdeadline = 0;
                relay_report(n, true, NET_END_NORMAL);
            } else if (m.type == RM_WAITING) {
                ctl_attach(n, &m);
            } else if (m.type == RM_PING) {
                RelayMsg pong = { .type = RM_PING };
                queue_relay(&n->cout, &pong);
            } else {
                ctl_down(n, NET_END_BAD_DATA);
                return;
            }
        }
    }
}

static void ctl_write(Net *n) {
    while (bytes_pending(&n->cout) > 0) {
        ssize_t w = send(n->cfd, n->cout.p + n->cout.pos, bytes_pending(&n->cout), MSG_NOSIGNAL);
        if (w > 0) {
            n->cout.pos += (size_t)w;
            continue;
        }
        if (w < 0 && errno == EINTR) continue;
        if (w < 0 && (errno == EAGAIN || errno == EWOULDBLOCK)) return;
        ctl_down(n, NET_END_LOST);
        return;
    }
    n->cout.pos = n->cout.len = 0;
}

static void ctl_timers(Net *n, uint64_t now) {
    if (n->cstate == CTL_DOWN && now >= n->cretry) ctl_connect(n);
    else if (n->cstate == CTL_HELLO && now >= n->cdeadline) ctl_down(n, NET_END_UNREACHABLE);
    else if (n->cstate == CTL_UP && now - n->clast_rx >= NET_RELAY_DEAD_MS) ctl_down(n, NET_END_LOST);
}

/* Milliseconds until ctl_timers has something to do. */
static int ctl_timeout(const Net *n, uint64_t now) {

                : n->cstate == CTL_HELLO   ? n->cdeadline
                                           : n->clast_rx + NET_RELAY_DEAD_MS;
    return at > now ? (int)(at - now) : 0;
}
```

```c
/* NET_EV_RELAY: the relay accepted our room, or lost it. */
static void host_relay(const NetEvent *ev) {
    if (ev->up && !S.codeReady) {
        S.codeReady = true;
        char code[JOINCODE_MAX_LEN];
        if (!publish_code(code)) return;
        console_log("Hosting via relay %s. Join code copied to clipboard.", S.relay);
        console_log("Join code: %s", code);
    } else if (ev->up) {
        console_log("Relay connection restored.");
    } else if (!S.codeReady) { /* the first attempt failed: we are not hosting */
        if (ev->end == NET_END_RELAY_FULL) console_log("The relay is full (too many rooms). Try again later.");
        else if (ev->end == NET_END_ROOM_TAKEN) console_log("The relay refused the room. Try :host again.");
        else if (ev->end == NET_END_VERSION)
            console_log("The relay speaks a different version. Update the game or the relay.");
        else console_log("Could not reach the relay %s. Use :host --direct to host without it.", S.relay);
        end_host();
    } else {
        console_log("Lost the relay; players cannot join until it is back. Retrying...");
    }
}
```

````markdown
# toh-relay on a TrueNAS home server

With the relay, the GM needs no router setup: the GM's game and the players both connect out to it, and it
copies bytes between them. It cannot read the game (everything is encrypted with a key only the join code holds).
Only the server needs one open port.

## Build

    make relay              # build/toh-relay: one static binary, no dependencies

## Install (once)

1. Copy the binary to the NAS (replace `<user>@<nas>`):

       ssh <user>@<nas> 'mkdir -p /mnt/Main/apps/toh-relay'
       scp build/toh-relay <user>@<nas>:/mnt/Main/apps/toh-relay/toh-relay
       ssh <user>@<nas> 'chmod 755 /mnt/Main/apps/toh-relay/toh-relay'

2. TrueNAS: Apps -> Discover Apps -> Install via YAML, name `toh-relay`, paste `compose.yaml`.
   The app log shows `listening on port 41234`.

3. Router (FRITZ!Box): Internet -> Permit Access -> Port Sharing -> Add Device for Sharing -> the NAS ->
   New Sharing -> Port Sharing, protocol TCP, port 41234 to 41234, with both IPv4 and IPv6 enabled.
   Note the MyFRITZ! address the box shows for the NAS (`<nas>.<id>.myfritz.net`): it follows a changing
   IP address.

4. Build the game with that address: `make clean && make RELAY=<myfritz-address>:41234`.
   Or set it per run: `TOH_RELAY=<myfritz-address>:41234 ./toh`.

## Check from outside

    python3 -c 'import socket,sys; s=socket.create_connection((sys.argv[1],41234),5); s.sendall(b"TOHR\x02\x01"+bytes(16)); print(s.recv(16))' <myfritz-address>

prints `b'TOHR\x04\x02'` (the relay answers "no such room").

## Update

    make relay
    scp build/toh-relay <user>@<nas>:/mnt/Main/apps/toh-relay/toh-relay.new
    ssh <user>@<nas> 'mv /mnt/Main/apps/toh-relay/toh-relay.new /mnt/Main/apps/toh-relay/toh-relay'

then restart the app (Apps -> toh-relay -> Restart). Copying to a new name first avoids "text file busy".
````
